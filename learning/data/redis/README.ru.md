# Обучение: Redis

Научитесь замечать, где существующая система тихо злоупотребляет Redis, например использует кеш как хранилище или блокировку, которая блокировкой не является, и вместо этого проектировать корректное использование с нуля.

**Последний урок:** [17. ACL и защищённый режим](lessons/0017-acls-and-protected-mode.md)

## Каким выглядит результат

- Глядя на то, как существующая система использует Redis, вы определяете, считает ли она кеш надёжным хранилищем, неверно ли реализует блокировку или держит неограниченное пространство ключей, и говорите, что из-за этого ломается.
- Вы с нуля проектируете корректное использование Redis (ограниченное пространство ключей, подходящая политика вытеснения, настоящая распределённая блокировка) для нового сценария.
- Вы сравниваете гарантии персистентности Redis (RDB/AOF) с надёжностью Postgres на основе WAL и говорите, когда взять Redis вместо базы данных правильно, а когда это антипаттерн.
- Вы рассуждаете о Redis Cluster/Sentinel на уровне компромиссов, которые вносит кластеризация, не нуждаясь в том, чтобы его эксплуатировать.

## Ограничения

- Опыт работы с Redis не предполагается.
