# 学习：蒸馏

通过学习大模型的输出，训练一个较小的模型去做大模型能做的事，并清楚每一种蒸馏形式能迁移什么、不能迁移什么。学完之后，你能针对给定的任务和预算，在蒸馏、量化和直接训练小模型之间做出选择，诚实地度量学生丢掉了什么，并评审别人所说的蒸馏模型“与教师相当”的声明。

**最新课程：** [27. 当惯常答案出错时](lessons/0027-when-the-usual-answer-is-wrong.md)

## 成功的标准

- 解释为什么教师的软目标比硬标签携带更多训练信号，并为一次蒸馏运行设定温度和损失权重。
- 写出 LLM 的 token 级蒸馏损失，在前向 KL 与反向 KL 之间做出选择，并说明分词器不匹配在什么时候会排除 logit 蒸馏。
- 在序列级做蒸馏，或者从教师生成的数据中蒸馏，并说清各自能迁移而对方不能迁移的东西。
- 构建一份经过质量过滤的合成蒸馏数据集，并核查教师的许可与条款是否允许用它的输出来训练。
- 解释暴露偏差，并说明在策略蒸馏相比在固定的教师输出上训练，什么时候值得付出它的成本。
- 预测学生会继承教师的哪些东西、不会继承哪些，包括它吸收不了的能力，以及没有人打算传下去的特质。
- 选择学生的规模和数据量，并把教师自身的成本计入预算。
- 对照教师，也对照一个同样大小、不经蒸馏训练的模型，度量学生丢掉了什么。
- 在蒸馏、量化和直接微调小模型之间做出选择；通过指出一项蒸馏声明隐藏了什么来评审它；用学生替换别人所依赖的模型；并说明惯常的答案在什么时候是错的。

## 约束

- 假定你能自如地阅读 Python 和 PyTorch，并且知道交叉熵损失、softmax 和训练循环是什么。不需要事先了解蒸馏，也不需要强化学习的知识，只要知道从模型中采样这个概念即可。
- 以论文和模型报告为依据。凡是某个数字只是一篇论文在它自己的设置上得到的结果，课程里都会明说，因为蒸馏的结果在很大程度上取决于教师、学生和数据。
- 第 1 和第 2 阶段的练习可以在笔记本电脑上进行，用的是小到 CPU 就能跑的分类器。后面的练习在两个小型开源模型之间做蒸馏，一台免费的 GPU 笔记本就够用。

## 范围之外

- 通过在推理模型的长思维链上做微调来蒸馏推理模型：见 [`llm/post-training`](../../llm/post-training/)，第 0014 课。那一课仍然是推理模型这个特例；本系列讲的是一般意义上的蒸馏，并链接过去，而不重述它。
- 通过 LoRA 或 QLoRA 适配器来运行监督微调：见 [`llm/finetuning`](../../llm/finetuning/)。本系列负责的是蒸馏的目标和数据；如何把训练应用到更少的参数上，则留在那边。
- 运行一次预训练：见 [`llm/pretraining`](../../llm/pretraining/)。把蒸馏当作预训练信号，在这里是作为一种损失和一种数据选择来讲的（第 0007 课），而不是作为一次预训练运行。
- 搭建评测：见 [`llm/evals`](../../llm/evals/) 及其[上线与否](../../llm/evals/reference/go-no-go.md)参考表。本系列用评测来比较学生与教师，不重新讲如何搭建评测。
- 通过降低精度来缩小模型：见 [`llm/quantization`](../../llm/quantization/)。本系列讲的是缩小模型的另一条路，即减少参数，两者的比较是第 9 阶段的一部分。
- 把剪枝作为一种独立的方法。第 0007 课展示了它在 Minitron 中与蒸馏配合使用，但只讲其中蒸馏的那一半。

## 学习路线

共九个阶段，从为什么小模型能向大模型学习，到评审他人蒸馏工作的判断力。一个阶段包含若干课程，边界并不严格；一个阶段是否完成，取决于能力，而不是课程数量。

| 阶段 | 课程 | 内容 | 完成的标志 |
|---|---|---|---|
| 1. 蒸馏为什么有效 | 0001 至 0003 | 教师与学生、软目标及其携带的信息、温度与组合损失 | 能说清为什么软目标比硬标签教得更多，并能设定温度 |
| 2. 面向 LLM 的 logit 蒸馏 | 0004 至 0007 | token 级蒸馏、前向 KL 与反向 KL、共享分词器的约束、作为预训练信号的蒸馏 | 能写出 token 级损失，并说明它什么时候无法使用 |
| 3. 序列级蒸馏 | 0008 至 0009 | 在教师解码出的输出上训练，以及在 token 级与序列级之间做选择 | 能说清每个层级迁移什么，并根据教师暴露出来的内容选定其一 |
| 4. 合成数据蒸馏 | 0010 至 0013 | 生成的指令数据、推理依据与解释轨迹、过滤、许可与条款 | 能构建一份经过过滤的蒸馏数据集，并核查它的使用是被允许的 |
| 5. 在策略蒸馏 | 0014 至 0016 | 暴露偏差、GKD 与 MiniLLM、在策略训练的成本与收益 | 能说明在策略蒸馏什么时候值回它的成本 |
| 6. 学生继承什么 | 0017 至 0019 | 保真度与泛化、模仿差距、容量差距、无意中传下去的特质 | 能预测学生会从教师那里学到什么、学不到什么 |
| 7. 确定规模 | 0020 至 0021 | 蒸馏缩放定律、数据量、预算中教师的成本 | 能选定学生的规模和数据量，并为算力辩护 |
| 8. 度量丢掉了什么 | 0022 至 0023 | 与教师的一致程度对比任务质量、基线、留出任务、数据污染 | 能度量学生丢掉了什么，并为这个数字辩护 |
| 9. 判断 | 0024 至 0027 | 蒸馏、量化还是微调小模型，评审一项声明，替换别人依赖的模型，惯常答案何时出错 | 值得信任去对一次蒸馏做出判断，并向他人解释清楚 |

## 课程

请按顺序学习。

| # | 课程 | 内容 |
|---|---|---|
| [0001](lessons/0001-what-distillation-buys.md) | 蒸馏能带来什么 | 一个小的学生模型被训练去模仿大的教师模型，以及为什么模仿可以胜过只用标签训练学生 |
| [0002](lessons/0002-soft-targets.md) | 软目标 | 教师给错误答案的概率里携带着什么，以及为什么它们是比硬标签更丰富的训练信号 |
| [0003](lessons/0003-temperature.md) | 温度 | 用温度把两个分布都变柔和、T 的平方修正，以及混入硬标签损失 |
| [0004](lessons/0004-token-level-distillation.md) | token 级蒸馏 | 在序列的每个位置上匹配教师的下一个 token 分布 |
| [0005](lessons/0005-forward-and-reverse-kl.md) | 前向 KL 与反向 KL | 为什么前向 KL 让学生铺开去覆盖教师的每一个模式，而反向 KL 让它只认定一个 |
| [0006](lessons/0006-the-tokenizer-constraint.md) | 分词器的约束 | 为什么 logit 蒸馏需要共享词表，以及跨分词器的方法放弃了什么 |
| [0007](lessons/0007-distilling-during-pretraining.md) | 预训练期间的蒸馏 | Gemma 2 和 Minitron 如何在大规模上把教师的分布当作训练信号，以及存储 logit 的代价 |
| [0008](lessons/0008-sequence-level-distillation.md) | 序列级蒸馏 | 在教师解码出的输出上，而不是在它的分布上训练学生 |
| [0009](lessons/0009-token-or-sequence.md) | token 级还是序列级 | 每个层级迁移什么、如何把二者结合，以及根据教师暴露的是 logit 还是只有文本来选择 |
| [0010](lessons/0010-distilling-from-generated-data.md) | 从生成数据中蒸馏 | 用教师的生成结果构建指令数据集，就像 Self-Instruct 和 Alpaca 所做的那样 |
| [0011](lessons/0011-rationales-and-explanation-traces.md) | 推理依据与解释轨迹 | 不仅在教师的答案上训练，也在它的推理上训练，就像 Distilling Step-by-Step 和 Orca 所做的那样 |
| [0012](lessons/0012-filtering-synthetic-data.md) | 过滤合成数据 | 在用生成数据训练之前，先检查、过滤并去重，因为数量弥补不了糟糕的样本 |
| [0013](lessons/0013-licensing-and-terms.md) | 许可与条款 | 服务商的条款和开源模型的许可，允许你对它的输出做什么 |
| [0014](lessons/0014-exposure-bias.md) | 暴露偏差 | 为什么在教师前缀上训练的学生，在推理时会遇到自己的错误，而训练时从未见过它们 |
| [0015](lessons/0015-gkd-and-minillm.md) | GKD 与 MiniLLM | 从学生那里采样、由教师来打分，以及随之而来的散度与混合方式的选择 |
| [0016](lessons/0016-on-policy-distillation-in-practice.md) | 在策略蒸馏的实践 | 在策略蒸馏每一步的成本、它换来什么，以及 Qwen3 如何把它用在自己的小模型上 |
| [0017](lessons/0017-fidelity-and-generalization.md) | 保真度与泛化 | 为什么泛化得很好的学生仍然可能与教师不一致，以及二者你需要哪一个 |
| [0018](lessons/0018-the-imitation-gap.md) | 模仿差距 | 为什么模仿更强的模型，复制它的风格要比复制它的能力快得多 |
| [0019](lessons/0019-capacity-gap-and-hidden-traits.md) | 容量差距与隐藏特质 | 为什么更大的教师并不总是更好的教师，以及什么东西会在无人有意的情况下传给学生 |
| [0020](lessons/0020-choosing-student-size.md) | 选择学生模型的规模 | 蒸馏缩放定律怎么说：蒸馏什么时候胜过直接训练学生 |
| [0021](lessons/0021-data-volume-and-teacher-cost.md) | 数据量与教师成本 | 把教师的推理计入预算，并判断多少蒸馏数据才算够 |
| [0022](lessons/0022-student-against-teacher.md) | 学生与教师的对比 | 把与教师的一致程度和任务质量分开度量，一次只看一种能力 |
| [0023](lessons/0023-an-honest-distillation-eval.md) | 一份诚实的蒸馏评测 | 让“与教师相当”这个数字站得住脚的基线、留出任务和数据污染检查 |
| [0024](lessons/0024-distill-quantize-or-fine-tune.md) | 蒸馏、量化还是微调 | 根据任务和预算，在更少的参数、更少的比特和直接训练小模型之间做选择 |
| [0025](lessons/0025-reviewing-a-distillation-claim.md) | 评审一项蒸馏声明 | 通过指出度量隐藏了什么，来评审“我们的小模型与大模型相当” |

## 使用方式

每节课都简短且自成一体。答案默认折叠：先自己回忆，再展开查看。真实场景中的练习比阅读更重要，而把练习间隔开来正是关键。课程结束时仍不清楚的地方，值得先追溯到一手资料再继续往下学。
