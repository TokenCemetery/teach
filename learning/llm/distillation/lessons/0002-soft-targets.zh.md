# 第 2 课：软目标

**使命关联:** 本使命要求你解释为什么教师的软目标比硬标签携带更多训练信号，而本课就是这个解释，并附有一次可以用来验证它的运行。
**主要来源:** [论文：“Distilling the Knowledge in a Neural Network”，Hinton、Vinyals 和 Dean，2015](https://arxiv.org/abs/1503.02531)
**前置知识:** [第 1 课](0001-what-distillation-buys.md)、[软目标](../GLOSSARY.md)、[硬标签](../GLOSSARY.md)、[logit](../GLOSSARY.md)

## 热身

1. ▢ 在一次蒸馏中，训练期间哪个模型的权重会变，哪个模型是训练信号？

<details markdown="1"><summary>检查</summary>

只有[学生模型](../GLOSSARY.md)在学习。[教师模型](../GLOSSARY.md)是固定的，负责提供目标。把这两者弄混，是阅读蒸馏损失时通常最先犯的错误。

</details>

2. ▢ 800 单元的 MNIST 网络单独训练时出现 146 个错误，当它同时匹配 1200 单元网络的输出时只有 74 个。这个 74 说明了目标里携带着什么？

<details markdown="1"><summary>检查</summary>

目标携带的是关于如何泛化的知识，由教师从抖动过的训练数据中学到，而学生在自己的迁移集中从未见过这些数据。每张图像的一个硬标签里没有任何这类信息。

</details>

## 要点

### 硬标签丢掉了什么

训练好的分类器会给大多数图像的正确类别一个接近 1 的概率。错误类别上那些微小的概率，仍然会因图像而异。Hinton 等人给了一个 MNIST 的例子：某个版本的 2，被判成 3 的概率可能是 10^-6，被判成 7 的概率是 10^-9，而另一个版本的 2 则可能正好相反。这说明了哪些 2 长得像 3、哪些 2 长得像 7，这是数据上的一种相似性结构。而[硬标签](../GLOSSARY.md)对这两个都只说“2”。

论文把由这些概率构成的训练目标称为软目标。它们所携带的信息，有时被称为暗知识，这个名字并没有出现在这篇论文里。本系列用[软目标](../GLOSSARY.md)指称这个目标，避免使用另一个说法。

### 问题所在：很小的数几乎不会推动损失

同一段话里点出了这个问题。在迁移期间，如此接近零的概率，对交叉熵代价的影响非常小。设想一个学生，给 2 的概率是 0.98，给 3 的概率是 0.01，而教师给的是 1.0 和 10^-6。2 对损失的贡献约为 0.0202，3 约为 0.0000046，小了 4000 多倍。信号是存在的，只是损失对它充耳不闻。

论文说，Caruana 及其合作者是这样避开这个问题的：用平方误差去匹配 logit，而不是去匹配概率。Hinton 等人更一般的答案，是把温度升高到目标足够柔和、能起作用为止，这就是第 3 课的内容。

### 亲眼看它运行

这个脚本在五个数字类别上构造一个教师，再构造两个学生。二者预测“2”的置信度相同。学生 A 相对于教师把 3 和 7 的顺序调换了，学生 B 则保持了教师的顺序。

```python
import numpy as np

def softmax(z, T=1.0):
    z = np.asarray(z, float) / T
    e = np.exp(z - z.max())
    return e / e.sum()

def kl(p, q):
    return float(np.sum(p * np.log(p / q)))

teacher = [9.0, 4.0, 2.0, 0.0, -4.0]    # classes: 2, 3, 7, 8, 0
student_a = [9.0, 1.0, 4.0, 0.0, -4.0]  # same top class, 3 and 7 swapped
student_b = [9.0, 4.0, 2.5, 0.0, -4.0]  # same ranking as the teacher

for T in (1, 5):
    p = softmax(teacher, T)
    print("T =", T)
    for name, z in (("A", student_a), ("B", student_b)):
        q = softmax(z, T)
        ce = -np.log(softmax(z)[0])
        print("  student", name, "hard-label CE %.4f" % ce, "KL(teacher||student) %.4f" % kl(p, q))
```

运行之前先预测：针对标签“2”的硬标签交叉熵更偏爱哪个学生，相对于教师的散度又更偏爱哪个？在 NumPy 2.5 上它打印出这样的结果：

```text
T = 1
  student A hard-label CE 0.0072 KL(teacher||student) 0.0177
  student B hard-label CE 0.0083 KL(teacher||student) 0.0001
T = 5
  student A hard-label CE 0.0072 KL(teacher||student) 0.0414
  student B hard-label CE 0.0083 KL(teacher||student) 0.0006
```

硬标签略微偏爱 A，也就是相似性结构错误的那个学生。相对于教师的散度则大幅偏爱 B。这些数字是为演示而构造的，所以请看方向，不要看大小。这里的 `KL` 散度，指的是教师分布相对于学生分布的 [KL 散度](../GLOSSARY.md)。

### 为什么这对语言模型更重要

论文中关于熵的那段话，直接适用于语言模型。当软目标的熵较高时，每个训练样本提供的信息比硬目标多得多。下一个 token 的分布很少接近 one-hot：许多续写都是合理的。Minitron 的作者在一个关于蒸馏损失的附录里说，LLM 的 logit 分布比分类模型那种尖锐的分布熵更高（Muralidharan 等，2024，附录 A.3）。他们的观察针对的是他们那套设置，但指向同一个方向。

### 关于学生从未见过的类别的信息

论文把迁移集中所有的 3 都删掉了，所以学生从未见过 3。它仍然只出现了 206 个测试错误，其中 133 个出在 1010 个测试用的 3 上。大部分错误来自学到的 3 类偏置过低。把这个偏置提高 3.5（这个选择是为了优化整体测试表现），它出现了 109 个错误，其中 3 上有 14 个，并且答对了 98.6% 的测试 3。关于 3 长什么样的知识，是通过其他数字的软目标传过来的。

## 练习

1. ▢ 在上面的运行中，T = 1 时，硬标签交叉熵更偏爱哪个学生，教师散度又更偏爱哪个？

<details markdown="1"><summary>提示</summary>

先比较两个 CE 数字，再比较两个 KL 数字，并想想每种损失能看到什么。

</details>

<details markdown="1"><summary>检查</summary>

针对标签“2”的交叉熵偏爱 A（0.0072 对 0.0083）。教师散度偏爱 B（0.0001 对 0.0177）。硬标签只看得到“2”的概率。A 把 3 和 7 的顺序弄错了，这对它是不可见的，而软目标携带的恰恰就是这个顺序。

</details>

2. ▢ 为什么在温度 1 下训练学生时，教师在错误类别上的微小概率几乎没有帮助？

    - a) 只有正确类别那一项会进入损失
    - b) 错误类别的项在计算损失之前就被丢弃
    - c) 每一项都按其目标概率来缩放
    - d) 学生的 softmax 无法输出非常小的值

<details markdown="1"><summary>检查</summary>

**c)** 交叉熵的每一项，都是目标概率乘以学生概率的对数。10^-6 的目标，权重只有接近 1 的目标的百万分之一。不是 (b)：没有任何东西把它们移除。不是 (a)：那描述的是硬标签损失，而不是软目标损失。不是 (d)：softmax 输出 10^-9 毫无问题。

</details>

3. ▢ 一个在没有 3 的迁移集上训练的学生，在把 3 类的偏置提高之后，答对了 98.6% 的测试 3。它是怎么知道 3 是什么的？

<details markdown="1"><summary>检查</summary>

教师在其他数字（例如 2、5 和 8）上的软目标，给 3 分配了很小的概率。这些概率教会学生哪些特征会抬高 3 的得分，而训练样本里一个 3 也没有。这个类别学到的偏置低得多，所以是知识本身已经在那里，只是偏移量错了。这个结果出自论文，在 MNIST 上，且只调整了一个偏置。

</details>

4. ▢ 教师给 2 的概率是 1.0，给 3 的概率是 10^-6。学生给它们 0.98 和 0.01。在交叉熵里，3 的那一项比 2 的那一项小大约多少倍？

<details markdown="1"><summary>提示</summary>

每一项都是教师的概率乘以学生概率的自然对数的相反数。

</details>

<details markdown="1"><summary>检查</summary>

2 的那一项是 -1.0 \* ln(0.98)，约 0.0202。3 的那一项是 -10^-6 \* ln(0.01)，约 0.0000046。比值约为 4400，所以小了 4000 多倍。这就是为什么论文让这些项起作用的办法是升高温度，而不是简单地相信损失。

</details>
