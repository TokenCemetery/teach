# 第 3 课：温度

**使命关联:** 本使命要求你设定一次蒸馏运行的温度和损失权重，而本课给出这个设定的三个组成部分：温度、T 平方因子，以及硬标签损失的权重。
**主要来源:** [论文：“Distilling the Knowledge in a Neural Network”，Hinton、Vinyals 和 Dean，2015](https://arxiv.org/abs/1503.02531)
**前置知识:** [第 2 课](0002-soft-targets.md)、[温度](../GLOSSARY.md)、[组合损失](../GLOSSARY.md)、[logit](../GLOSSARY.md)

## 热身

1. ▢ 在温度 1 下，学生给 2 的概率是 0.98，给 3 的概率是 0.01，而教师给的是 1.0 和 10^-6。为什么 3 几乎没有推动损失？

<details markdown="1"><summary>检查</summary>

交叉熵的每一项，都是目标概率乘以学生概率的对数。3 的目标是 10^-6，使它的那一项比 2 的那一项小了 4000 多倍，所以其中的信息存在，却几乎没人听见。

</details>

2. ▢ 硬标签对 2 与 7 的相似性说了什么？在一次蒸馏中，这个信息在哪里？

<details markdown="1"><summary>检查</summary>

什么也没说。相似性存在于[教师模型](../GLOSSARY.md)放在错误类别上的小概率里，也就是[软目标](../GLOSSARY.md)里。

</details>

## 要点

### 温度

论文把 softmax 换成这样一种：归一化之前，先把每个 [logit](../GLOSSARY.md) 除以温度 T：q_i = exp(z_i / T) / sum_j exp(z_j / T)。T 通常是 1。T 越高，类别上的分布越柔和。论文的做法是，把 T 升到教师产生足够柔和的软目标为止，然后在同样的高 T 下训练学生去匹配它们。训练之后，学生使用 T = 1。

```python
import numpy as np

def softmax(z, T=1.0):
    z = np.asarray(z, float) / T
    e = np.exp(z - z.max())
    return e / e.sum()

logits = [9.0, 4.0, 2.0, 0.0, -4.0]   # classes: 2, 3, 7, 8, 0
np.set_printoptions(suppress=True, precision=4)
for T in (1, 2, 5, 20):
    print("T =", T, softmax(logits, T))
```

运行之前，先预测 T = 5 时第一个类别的概率。在 NumPy 2.5 上的输出：

```text
T = 1 [0.9923 0.0067 0.0009 0.0001 0.    ]
T = 2 [0.889  0.073  0.0268 0.0099 0.0013]
T = 5 [0.5394 0.1984 0.133  0.0892 0.0401]
T = 20 [0.2745 0.2138 0.1934 0.175  0.1433]
```

T = 1 时，错误类别的概率加起来不到 1%。T = 5 时，它们携带了近一半的概率，而 3、7、8、0 的顺序仍然看得出来。T = 20 时，分布几乎是平的，学生需要匹配的差异很小。

### 为什么损失要乘以 T 的平方

当教师的 logit 是 v_i，两者都使用温度 T 时，交叉熵关于学生 logit z_i 的梯度是 (1/T)(q_i - p_i)。论文的公式 2 给出了它。如果 T 相对于 logit 很大，并且每个样本的 logit 都做了零均值化，论文表明这近似于 (1/(N T^2))(z_i - v_i)，其中 N 是类别数。所以在高温极限下，蒸馏等价于最小化 1/2 (z_i - v_i)^2，也就是 Caruana 及其合作者的 logit 匹配。匹配 logit 是蒸馏的一个特例。

实践中要紧的因子是 1/T^2。论文说，软目标梯度的量级按 1/T^2 缩放，所以同时使用硬目标和软目标时，把它们乘以 T^2 很重要。这样一来，在你试验其他设置、改变 T 时，两者的相对贡献大致保持不变。

```python
import numpy as np

def softmax(z, T=1.0):
    z = np.asarray(z, float) / T
    e = np.exp(z - z.max())
    return e / e.sum()

teacher = np.array([9.0, 4.0, 2.0, 0.0, -4.0])
student = np.array([6.0, 5.0, 0.0, 1.0, -2.0])
for T in (1, 2, 5, 10, 20):
    grad = (softmax(student, T) - softmax(teacher, T)) / T
    print(T, "%.4f" % np.abs(grad).max(), "%.4f" % (np.abs(grad).max() * T**2))
```

输出显示，最大的梯度分量从 T = 1 时的 0.2663 缩小到 T = 20 时的 0.0017。乘以 T 的平方之后，从 T = 2 到 T = 20，它一直保持在 0.64 到 0.84 之间。T = 1 那一行不是公平的比较，因为高温近似在那里并不成立。

### 组合损失

当迁移集有正确标签时，论文发现，在只用软目标训练的基础上，再训练学生去产出正确的标签，效果会更好。它尝试过用标签去修改软目标，发现把两个目标做加权平均更好。第一个目标是与软目标的交叉熵，在高 T 下计算。第二个是与正确标签的交叉熵，用同样的学生 logit，在 T = 1 下计算。论文发现，通常第二个目标的权重取得低得多，效果最好。

按本系列的记号来写，而不是论文的记号，用 lambda 表示软项的权重：

```text
loss = lambda * T^2 * CE(teacher at T, student at T) + (1 - lambda) * CE(label, student at 1)
```

这就是[组合损失](../GLOSSARY.md)。论文的语音实验在硬标签项上使用了 0.5 的相对权重，温度取 1、2、5 和 10。硬标签项取得小，原因很实际：学生通常无法完全匹配软目标，而论文说，偏向正确答案一些，结果证明是有帮助的。

DistilBERT 遵循同样的模式。它在训练期间对教师和学生都应用带温度的 softmax，推理时把 T 设为 1，并把自己的几项与软目标损失一起，同掩码语言建模损失和余弦嵌入损失做线性组合。

### 选择 T

论文在 MNIST 上给出两个观察。当蒸馏出的网络，两个隐藏层每层有 300 个以上的单元时，所有高于 8 的温度给出的结果相当接近。当每层缩减到 30 个单元时，2.5 到 4 之间的温度明显好于更高或更低的温度。作者认为，当学生太小，容纳不下教师的全部知识时，忽略那些很负的 logit（较低的温度会把它们的权重压低）可能有帮助。

不要把分类器上的温度照搬到语言模型上。Minitron 的作者在用教师重新训练剪枝后的 LLM 时，试过 0.1、0.5、1.0 和 3.0 这几个温度，报告说 1.0 的结果最好（附录 A.3）。他们解释了为什么要包含小于 1 的值：LLM 的 logit 分布比视觉模型那种尖锐的分布熵更高，所以他们预期变柔和的作用没那么大。第二项规模更大的研究也与此一致。Busbridge 等人（2025）对学生规模从 198M 到 1.82B 参数、各自由 546M 到 7.75B 的教师蒸馏而来的情形，把温度从 0.5 扫到 10，发现所有规模上的最佳表现都出现在 1（附录 G.2）。高于 3 的温度会有损害，而较小的学生受害最重。在附录 B.3 中他们说，与他们所引的文献相反，最优温度是 1，并推测差异在于早期工作用了重复的 token，而他们的设置不重复数据。这个推测是他们的，论文在这里并没有检验它。这两个发现都是某一个实验室在类似预训练的设置上得出的，所以请把它们当作在任何扫描中都要包含 T = 1 的有力理由，而不是高温永远没有帮助的证明。

Minitron 的消融同样只是一套设置。在他们的最终配方里，他们还发现单用 logit 损失，比它与语言建模损失的加权混合更好，这提醒我们，权重是要测试的设置，而不是常数。

## 练习

1. ▢ 使用 logit 9、4、2、0 和 -4，T = 5 时第一个类别大约得到多大的概率？

    - a) 大约 0.99
    - b) 大约 0.54
    - c) 大约 0.20
    - d) 大约 0.01

<details markdown="1"><summary>提示</summary>

把 logit 除以 5，各自取指数，再用第一个除以五个的总和。

</details>

<details markdown="1"><summary>检查</summary>

**b)** 缩放后的 logit 是 1.8、0.8、0.4、0 和 -0.8。它们的指数约为 6.05、2.23、1.49、1.00 和 0.45，总和约 11.22，6.05 / 11.22 是 0.54。选项 (a) 是 T = 1 时的答案。选项 (c) 是第二个类别，T = 5 时为 0.198，不是第一个。

</details>

2. ▢ 你把 T 从 4 升到 8，其他都不变。为什么论文要把软项乘以 T 的平方？

    - a) 为了抵消教师自己的温度设置
    - b) 为了确保软目标之和为一
    - c) 为了在测试时提高学生的置信度
    - d) 为了让软梯度与硬梯度保持平衡

<details markdown="1"><summary>检查</summary>

**d)** 软梯度按 1/T^2 缩小，所以没有这个因子的话，随着 T 增大，软项相对于硬项会逐渐消失。不是 (b)：softmax 已经做了归一化。不是 (c)：推理时学生运行在 T = 1，什么都不会被乘。不是 (a)：教师和学生共用同一个 T，没有哪一个被抵消。

</details>

3. ▢ 在论文的组合损失里，哪一项运行在高温下，哪一项运行在 T = 1，哪一项通常取较低的权重？

<details markdown="1"><summary>检查</summary>

与教师软目标的交叉熵运行在高 T 下，使用除以 T 之后的学生 logit。与正确标签的交叉熵在同样的 logit 上运行，T = 1。论文发现，通常硬标签项的权重取得低得多，效果最好。权重是你要调的设置，所以要说明一个结果用的是哪一组。

</details>

4. ▢ 一位同事把 MNIST 上 T = 20 的设置照搬到一次 LLM 蒸馏中，得到了更差的学生。本课中有什么线索能说明原因，他们应该怎么做？

<details markdown="1"><summary>检查</summary>

Minitron 在 0.1、0.5、1.0 和 3.0 上的消融，以及 Busbridge 从 0.5 到 10 的扫描，都发现 1 的结果最好，而且 Minitron 的作者说，LLM 的 logit 分布比视觉模型那种尖锐的分布熵更高。在 T = 20 时，上面代码片段里的目标几乎是平的，所以学生必须学的差异很小。他们应该针对自己的教师和学生做一次包含 T = 1 的简短扫描。这两个发现各自只来自一套设置，所以是一个起点，而不是一条规则。

</details>

5. ▢ 在论文的 MNIST 实验中，哪个学生对温度的选择更敏感，是有 300 个以上隐藏单元的那个，还是有 30 个的那个？对敏感的那个来说，哪个范围有效？

<details markdown="1"><summary>检查</summary>

30 单元的学生。对它来说，2.5 到 4 之间的温度明显好于更高或更低的温度，而有 300 个以上单元时，高于 8 的一切温度给出的结果相当接近。论文对此的解读是：当学生太小，容纳不下教师的全部知识时，忽略很负的 logit 会有帮助。

</details>
