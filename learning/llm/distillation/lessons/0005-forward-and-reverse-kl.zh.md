# 第 5 课：前向 KL 与反向 KL

**使命关联:** 本使命要求你在前向 KL 与反向 KL 之间做出选择，而本课给出这两个方向、能把二者区分开的玩具案例，以及在该用哪一个上意见不一的几篇论文。
**主要来源:** [论文：“MiniLLM: On-Policy Distillation of Large Language Models”，Gu 等，2023](https://arxiv.org/abs/2306.08543)
**前置知识:** [第 4 课](0004-token-level-distillation.md)、[前向 KL](../GLOSSARY.md)、[反向 KL](../GLOSSARY.md)、[KL 散度](../GLOSSARY.md)

</details>

<details markdown="1"><summary>检查</summary>

这一项是教师的概率乘以一个对数比，所以 10^-6 的目标把它缩小了百万倍。请记住这一点：KL 的方向，决定了由谁的概率来做这个缩放。

</details>

## 要点

### 同一个散度的两个方向

KL 散度不是对称的。设 p 是教师，q 是学生，[前向 KL](../GLOSSARY.md) 是 KL(p || q)，即对 token 求和的 p log(p / q)。[反向 KL](../GLOSSARY.md) 是 KL(q || p)，即 q log(q / p) 之和。唯一的差别，是由谁的概率乘在对数比上，而这决定了各自惩罚什么。GKD（Agarwal 等，2023，第 2 节）用的就是这两个名字。

前向 KL 按教师的概率给每个 token 加权。教师喜欢、学生却几乎不给概率的 token，代价很大，因为比值 p / q 极大。教师几乎不给、学生却喜欢的 token，代价很小，因为 p 很小。学生被推着在教师有概率质量的每一处都放一些质量，这就是覆盖模式。

反向 KL 按学生的概率给每个 token 加权。学生把质量放在教师几乎没有质量的地方，会受到惩罚，因为那里 q log(q / p) 很大。忽略教师的某个模式不用付出任何代价，所以学生可以自由地只取其中一个。这就是寻找模式。

### 两个模式，两个学生

下面的教师有两个同样可能的续写，另外两个只有一点点概率。第一个学生把质量铺开。第二个学生只认定一个模式。

```python
import numpy as np

p = np.array([0.49, 0.01, 0.01, 0.49])        # teacher: two modes
students = {
    "spread": np.array([0.25, 0.25, 0.25, 0.25]),
    "commit": np.array([0.97, 0.01, 0.01, 0.01]),
}

def kl(a, b):
    return float(np.sum(a * np.log(a / b)))

for name, q in students.items():
    print(name, "forward %.3f" % kl(p, q), "reverse %.3f" % kl(q, p))
```

先预测每个方向会偏爱哪个学生，再运行。在 NumPy 2.5 上的输出：

```text
spread forward 0.595 reverse 1.273
commit forward 1.572 reverse 0.623
```

前向 KL 偏爱铺开的学生（0.595 对 1.572），它在两个模式上都放了概率，并在两个罕见 token 上浪费了一些。反向 KL 偏爱认定一个的学生（0.623 对 1.273），它停在一个模式上，忽略了另一个。两个学生都没有与教师吻合。你想要哪种失败，取决于学生接下来要做什么，这也是接下来两篇论文的论点。

### 支持反向 KL 的论证

Gu 等人认为，标准的蒸馏目标最小化的是一个近似的前向 KL，它迫使学生覆盖教师的所有模式。对分类任务来说，类别数有限，两个分布的模式都很少，这样做效果很好。对开放式生成来说，教师的模式可能比小学生所能表达的多得多。论文说，这时前向 KL 会让学生给教师几乎没有概率的区域分配高得不合理的概率，并在自由运行的生成过程中产生按教师来看极不可能的样本（引言）。他们的补救办法是反向 KL，它寻找主要的模式，并给教师的空白区域很低的概率。他们说，在文本上，学生避免学习教师分布中过多的长尾变体，转而专注于正确性。

他们在一个玩具例子上展示了这一效果：用单个高斯分布，分别按两种散度去拟合一个高斯混合（图 2）。他们用在学生样本上的策略梯度来优化反向 KL，并附加了一些保证稳定的步骤，这使它成为一种在策略方法。第 15 课会讲到它。损失本身很简单。用前面代码片段里的对数概率，逐位置的反向 KL 是 `(s.exp() * (s - t)).sum(dim=-1)`，替换掉前向的那一行。

### 选择的论证

GKD 不站队。它把散度变成一个参数。它的广义 JSD，对 0 到 1 之间的系数 beta，是：

```text
JSD(beta)(P || Q) = beta * KL(P || beta*P + (1-beta)*Q) + (1-beta) * KL(Q || beta*P + (1-beta)*Q)
```

以 P 为教师，它在两个方向之间插值。当 beta 趋近 0 时，梯度的行为像前向 KL，当 beta 趋近 1 时，像反向 KL。即使支撑集不相交，它也是有界的，而 KL 不是（第 2 节）。在同一个玩具例子上，用根据该公式写出的 `jsd` 函数（不在论文里），三个 JSD 的值给出一个交叉：

| 学生 | JSD(0.1) | JSD(0.5) | JSD(0.9) |
|---|---|---|---|
| 铺开 | 0.055 | 0.177 | 0.091 |
| 认定一个 | 0.102 | 0.189 | 0.058 |

beta = 0.1 时铺开的学生胜出，beta = 0.9 时认定一个的学生胜出，这与两端各自被说成偏爱的方向一致。在 0.5 时二者接近。这些数字来自玩具例子，不是来自任何一次运行。

GKD 的实验说明，最佳的散度取决于任务。在 XSum 摘要任务上，沿 JSD 族从前向 KL 移到反向 KL，输出的多样性下降了（图 4）。在消融中，用温度采样评估时，寻找模式的散度做得更好，而用贪心解码时，这个选择几乎无关紧要（第 4.1 节）。在 FLAN 上与任务无关的指令微调中，使用反向 KL 的在策略 GKD 大幅超过了监督 KD 和 ImitKD，而且那里反向 KL 比前向 KL 好得多（图 10）。在 GSM8K 上，前向 KL 表现相当好，反向 KL 也是，尤其是只在固定数据集上训练时。论文的总结是，散度必须依据任务上多样性与质量的权衡来选择。

TRL 的实现把这个选择暴露为 `GKDConfig` 中的 `beta`：为 0.0 时损失是 KL 散度，为 1.0 时是逆 KL，默认值是 0.5（[TRL 的 GKD 文档](https://huggingface.co/docs/trl/main/en/gkd_trainer)，为本课而读）。

### 反方向的证据

Minitron 的作者从未剪枝的教师重新训练剪枝后的基础模型，并直接测试了这两个方向。在深度剪枝的 Minitron 8B 上，使用前向 KLD 的 logit 损失达到了 2.155 的语言建模损失，而反向 KLD 是 2.665（他们的表 16，附录 A.3）。在上一代 Nemotron-3 8B 上，组合损失在前向 KLD 下是 2.117，反向是 2.140（表 15）。他们指出，先前的工作发现反向 KLD 更适合监督微调和指令遵循，Agarwal 等人说这个选择取决于任务，而对他们的基础模型设置来说，前向 KLD 是最佳选择（第 4 节）。

所以证据并不是一条规则。反向 KL 得到 GKD 中小学生指令微调结果的支持，前向 KL 得到 Minitron 中重新训练基础模型的支持。两者都是单篇论文在各自模型上的结果。

## 练习

1. ▢ 在两个模式的运行里，前向 KL 偏爱哪个学生，反向 KL 又偏爱哪个？

<details markdown="1"><summary>提示</summary>

问一问，哪个学生在教师的两个大 token 上都放了一些概率，哪个忽略了其中一个。

</details>

<details markdown="1"><summary>检查</summary>

前向 KL 偏爱铺开的学生（0.595 对 1.572），反向 KL 偏爱认定一个的学生（0.623 对 1.273）。前向 KL 惩罚认定一个的学生，因为在 p 为 0.49 的地方它的 q 接近 0.01。反向 KL 惩罚铺开的学生，因为在 p 为 0.01 的地方它放了 0.25。

</details>

2. ▢ 论文反对在开放式生成中使用前向 KL 的论点是什么？

    - a) 损失无法由完整的分布计算出来
    - b) 学生必须覆盖比它所能表达的更多的模式
    - c) 当教师非常自信时，梯度总会消失
    - d) 教师的 logit 必须先变柔和，它才能起作用

<details markdown="1"><summary>检查</summary>

**b)** 文本上的教师，其模式比小学生所能表达的多得多，而前向 KL 迫使学生去覆盖它们，所以它会把质量放在教师认为空白的区域。不是 (a)：两个方向都可以由完整的分布计算出来。不是 (c)：那是第 2 课关于小概率的观察，是另一个问题。不是 (d)：温度是与方向无关的另一个选择。

</details>

3. ▢ 根据 JSD 表，JSD(0.9) 偏爱哪个学生？这是否符合 GKD 所说的 beta 接近 1 时行为像反向 KL？

<details markdown="1"><summary>检查</summary>

认定一个的学生（0.058 对 0.091），是的：反向 KL 也偏爱它。在 beta = 0.1 时，铺开的学生胜出，如同前向 KL 那样。这张表只是对论文描述的一次玩具验证，不是来自训练运行的结果。

</details>

4. ▢ Minitron 的表 16 给出，对深度剪枝的 8B 学生，前向 KLD 的语言建模损失是 2.155，反向 KLD 是 2.665。这是否与 MiniLLM 和 GKD 相矛盾？

<details markdown="1"><summary>检查</summary>

不，并不直接矛盾。MiniLLM 和 GKD 报告的是小学生上的指令遵循和摘要结果，且反向方向常常是在学生采样的序列上。Minitron 是在类似预训练的数据混合上重新训练剪枝后的基础模型，并度量语言建模损失。二者在任务、学生的起点和指标上都不同，所以证据支持的是一种取决于任务的选择，就像 GKD 所说的那样。在下定决心之前，请在你自己的任务上两个都测一测。

</details>

5. ▢ 哪个散度对教师的微小概率充耳不闻，就像第 2 课那样，而哪个会因为学生把质量放在那里而惩罚学生？

<details markdown="1"><summary>检查</summary>

前向 KL 对教师的微小概率几乎充耳不闻，因为是 p 乘在对数比上，这就是第 2 课的问题。反向 KL 会惩罚学生把质量放在教师几乎没有质量的地方，因为是 q 乘在对数比上。这两个方向，对同一个小数字回答的是相反的问题。

</details>
