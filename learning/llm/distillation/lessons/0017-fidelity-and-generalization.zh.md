# 第 17 课：保真度与泛化

**使命关联:** 本使命要求你预测学生会继承什么，并度量它丢掉了什么，这要从把它复制教师有多紧密，与它做任务有多好分开讲起。
**主要来源:** [论文：“Does Knowledge Distillation Really Work?”，Stanton 等，2021](https://arxiv.org/abs/2106.05945)，第 3 至 7 节
**前置知识:** [第 3 课](0003-temperature.md)、[第 16 课](0016-on-policy-distillation-in-practice.md)、[保真度](../GLOSSARY.md)、[前向 KL](../GLOSSARY.md)、[组合损失](../GLOSSARY.md)

## 热身

1. ▢ 组合损失加了两项。哪一项把学生拉向教师，哪一项把它拉向标签？

<details markdown="1"><summary>检查</summary>

相对于教师[软目标](../GLOSSARY.md)的散度，把它拉向教师，而针对[硬标签](../GLOSSARY.md)的交叉熵，把它拉向数据。由一个混合系数给它们加权。

</details>

2. ▢ Qwen3 的在策略阶段，在学生自己的样本上最小化学生与教师之间的 KL。教师到学生的形式是哪个方向的 KL？它惩罚什么？

<details markdown="1"><summary>检查</summary>

KL(teacher || student) 是前向 KL。它惩罚学生在教师给了很高概率的地方给得很低，所以它推动学生覆盖教师所覆盖的一切。

</details>

3. ▢ 在第 16 课里，Qwen3 的学生在基准上胜过了用强化学习训练的检查点。这是否说明学生的预测与它的教师相符？

<details markdown="1"><summary>检查</summary>

不是。基准分数度量的是任务。学生是否与教师的预测一致，是另一项单独的度量，而本课讲的就是为什么这两者会分开。

</details>

## 要点

### 蒸馏可能意味着它改进了的两样东西

Stanton 等人把蒸馏文献通常混为一谈的两个量分开了。**保真度**是学生匹配教师预测的能力。**泛化**是学生在未见过的、同分布数据上的表现。他们用同样输入上的两个数字来度量保真度，二者都定义在第 3.2 节：

| 指标 | 它度量什么 |
|---|---|
| 平均 top-1 一致率 | 学生与教师选出同一个最高概率标签的输入所占的比例 |
| 平均预测 KL | KL(teacher \|\| student) 的均值，对每个类别都敏感，而不只是最高的那个 |

准确率不能代替一致率。论文自己的例子：三个独立的模型，测试准确率分别是 55%、75% 和 95%。第一个和第三个最多只能在 60% 的输入上一致，而第二个和第三个至少在 70% 上一致，可是没有人会说 75% 的模型是 95% 模型更好的蒸馏，因为它们是独立训练的。

### “它们一致是因为两者都很好”的对照

仅仅因为模型准确，一致率就会上升。为了把整体的改进与在匹配上的具体改进区分开，论文还训练了第二个学生，用完全相同的流程，从一个独立的教师蒸馏得到。如果两个学生与第一个教师的一致程度差不多，一致就可以由泛化来解释。如果真正的学生与它自己的教师更一致，那才是保真度。

### 他们发现了什么

他们的实验大多是用 ResNet 在 CIFAR-100 上做的图像分类，另外还有 MNIST、ImageNet，以及附录里的一个文本分类数据集（IMDB 情感）。它们不是关于语言模型生成的实验，所以请把它们当作关于一般意义上蒸馏的结果来读，再在你自己的 LLM 这一对模型上测试。

| 发现 | 论文中的证据 |
|---|---|
| 容易的情形：匹配有效 | 在 MNIST 上，LeNet-5 在蒸馏数据足够时，测试集 top-1 一致率超过 99%（第 4.1 节） |
| 较难的情形：常常无效 | 在 CIFAR-100 上，ResNet-56 的自蒸馏，即使用最大的蒸馏集，测试一致率仍低于 80%（第 6.1 节） |
| 更好的泛化可能伴随更差的保真度 | 在自蒸馏中，用 GAN 样本扩大数据，提高了保真度，降低了测试准确率，因为匹配不了教师的学生可能泛化得更好（图 1a，第 4.2 节） |
| 教师更强时，两者一致 | 蒸馏一个 3 成员的集成时，随着数据增多，保真度和测试准确率都上升了（图 1b） |
| 不是容量问题 | 即使在学生拥有教师同样容量的自蒸馏中，也会出现低保真度，而在蒸馏集成时，扩大学生几乎没有改变它（第 4.4 节） |
| 不是某一种架构、规模或领域的问题 | 用 VGG、在 ImageNet 和 IMDB 上得到类似的结果（第 4.4 节） |

### 解释：优化

论文检验了对这种失败的两个假设。一个是可识别性：蒸馏数据太少，无法确定教师的函数。更多数据有助于测试一致率，所以这是故事的一部分。另一个是优化：学生甚至在它所训练的蒸馏数据上，也无法匹配教师。

第二个站得住脚。加入 5 万张合成图像之后，与教师有同样容量的学生，在蒸馏数据本身上也只达到了 95% 的一致率。在重度数据增强下，三种增强各自的训练一致率在 80% 到 90% 之间，而在自蒸馏中，三种增强的组合使它降到了约 60%（第 6.1 节）。训练更久有一点帮助：对 ResNet-20 的自蒸馏，SGD 训练 5,000 个轮次，训练一致率达到 83.3%，而 300 个轮次时是 78.95%，换成 Adam 则降低了保真度（第 6.2 节）。

论文的总结是一种权衡。加入教师训练数据之外的样本，给了学生更多教师标签来识别这个函数，同时也让本来就难的优化问题变得更难。用论文的话说，好的保真度与解决一个异常困难的优化问题直接挂钩，而普通训练是靠不需要把它解决好才得救的。

### 这对你意味着什么

如果你只用任务准确率来评估一个蒸馏出来的 LLM，你就无法判断你继承了教师的多少东西。两个学生可以得分相同，而在一致程度上差别很大。第 8 阶段会构建完整的度量，而最起码的习惯是这样：在任务质量旁边，报告在留出输入上与教师的一致率，并与从另一个教师蒸馏的学生，或者不经蒸馏训练的学生做比较。

保真度并不总是目标。论文自己的自蒸馏结果，显示了一个匹配不了教师、却泛化得更好的学生。当你想继承准确率之外的性质时，保真度才重要：论文列出了迁移校准或鲁棒性，使较小的模型可以安全地替换较大的模型（第 4.3 节）。它还发现，蒸馏集成时，保真度最高的学生始终是校准得最好的。

下面是两种度量的纯 Python 草图，它会打印出注释里所示的输出：

```python
import math

def softmax(z):
    m = max(z)
    e = [math.exp(v - m) for v in z]
    s = sum(e)
    return [v / s for v in e]

def argmax(z):
    return max(range(len(z)), key=lambda i: z[i])

def kl(p, q):
    return sum(pi * (math.log(pi) - math.log(qi)) for pi, qi in zip(p, q))

# One row per example: logits over three classes, plus the true label.
teacher = [[3.0, 1.0, 0.0], [0.5, 2.5, 0.0], [0.0, 0.5, 3.0], [1.0, 2.0, 0.0]]
student = [[2.0, 1.5, 0.0], [0.0, 1.0, 2.0], [0.0, 0.5, 2.5], [2.0, 1.5, 0.0]]
labels = [0, 1, 2, 0]

agreement = sum(argmax(t) == argmax(s) for t, s in zip(teacher, student)) / len(labels)
mean_kl = sum(kl(softmax(t), softmax(s)) for t, s in zip(teacher, student)) / len(labels)
teacher_acc = sum(argmax(t) == y for t, y in zip(teacher, labels)) / len(labels)
student_acc = sum(argmax(s) == y for s, y in zip(student, labels)) / len(labels)

print(f"agreement {agreement:.2f}  mean KL {mean_kl:.3f}")      # agreement 0.50  mean KL 0.321
print(f"teacher accuracy {teacher_acc:.2f}  student accuracy {student_acc:.2f}")  # both 0.75
```

两个模型的得分都是 0.75，而它们只在一半的输入上一致。

## 练习

1. ▢ 在同一个测试集上，教师的准确率是 93%，学生是 91%。它们的 top-1 一致率必定落在哪两个界之间？

<details markdown="1"><summary>提示</summary>

学生在 9% 的输入上错，教师在 7% 上错。这两组错误最多能重叠多少，最少又是多少？

</details>

<details markdown="1"><summary>检查</summary>

在 84% 到 98% 之间。它们在二者都对的地方一致，最坏的情形是它们的错误从不重叠，那样剩下的是 100 减 7 减 9，所以至少是 84%。它们最多能在 98% 上一致：学生比教师多错 2 个百分点的输入，所以至少有 2% 的输入是教师对、学生错。准确率匹配，对一致率几乎说明不了什么，这正是本课的要点。

</details>

2. ▢ 在论文的对照里，为什么要从一个独立的教师训练第二个学生？

    - a) 用来验证教师训练得是否正确
    - b) 用来把保真度与共有的能力分开
    - c) 用来提高第一个学生的准确率
    - d) 用来减少整体所需的算力

<details markdown="1"><summary>检查</summary>

**b)** 如果一个学生与独立教师的一致程度，和与它自己的教师差不多，那么一致是由二者都很好来解释的，而不是由复制来解释。(a) 在这里没有检验。(c) 和 (d) 是错的：第二个学生是一个度量工具，对第一个学生没有任何改变。

</details>

3. ▢ 在 CIFAR-100 的自蒸馏中，学生和教师都是 ResNet-56，蒸馏集用 GAN 生成的图像扩大。预测学生保真度和学生测试准确率的变化方向。

<details markdown="1"><summary>提示</summary>

自蒸馏是学生本来就有能力匹配教师的情形，而论文指出，匹配不上本身就可能有帮助。

</details>

<details markdown="1"><summary>检查</summary>

保真度上升，测试准确率下降（图 1a）。在自蒸馏中，与教师匹配得没那么紧密的学生泛化得更好，所以更高的保真度要用准确率来换。而教师是 3 成员集成时，方向翻转了：二者都上升（图 1b）。哪一种适用于你，取决于你的教师是否比独立训练的学生泛化得好得多。

</details>

4. ▢ 一个蒸馏出来的学生，架构与教师相同，却仍在 20% 的留出输入上与它不一致。列出论文检验过的假设，并说明它支持哪一个。

<details markdown="1"><summary>检查</summary>

学生容量、架构、数据集规模、数据领域、可识别性和优化（第 4.4 节）。论文排除了容量，因为学生拥有教师的容量，也依据自己的证据排除了其他几项。它支持把优化作为关键原因：学生甚至在它自己的训练输入上也匹配不了教师。可识别性也是图景的一部分，因为更多的数据提高了测试一致率。论文是在图像任务里发现这个巨大的一致率差距的，所以在假定它能延续到你的 LLM 之前，请先在你的这一对模型上检查。

</details>

5. ▢ 下列 LLM 度量中，哪一个最接近论文里的平均预测 KL？它需要一致率不需要的什么东西？

<details markdown="1"><summary>检查</summary>

留出序列上逐位置 KL(teacher || student) 的均值，也就是第 2 阶段的前向 KL token 级蒸馏损失，在没有用于训练的数据上做评估。它需要教师在每个位置上的完整分布，而最高 token 上的一致率不需要。最高 token 的一致率，是 top-1 一致率更便宜的类比。这种从论文的分类设置映射到 token 级的做法，是我的改编，不是论文里的实验。

</details>
