## Мягкие метки и температура

| Термин | Определение | Источник |
|---|---|---|
| Мягкие метки | Вероятности учителя по каждому классу, используемые как цель вместо жёсткой метки или рядом с ней | Hinton et al., 2015, раздел 1 |
| Softmax с температурой | q_i = exp(z_i / T) / sum_j exp(z_j / T). T = 1 это обычный softmax, более высокая T даёт более мягкое распределение | Hinton et al., уравнение 1 |
| Где используется T | Одна и та же высокая T для учителя и ученика во время обучения. Затем ученик работает при T = 1 | Hinton et al., раздел 2 |
| Градиент при температуре T | dC/dz_i = (1/T)(q_i - p_i). Для большой T и логитов с нулевым средним он примерно равен (1/(N T^2))(z_i - v_i), так что сопоставление логитов это частный случай | Hinton et al., раздел 2.1 |
| Множитель T в квадрате | Градиенты мягких меток масштабируются как 1/T^2, поэтому умножайте мягкую потерю на T^2, когда объединяете её с жёсткой | Hinton et al., раздел 2 |

Множитель в запуске, для логитов `[9, 4, 2, 0, -4]` против `[6, 5, 0, 1, -2]`: наибольший элемент градиента равен 0.2663 при T = 1 и 0.0017 при T = 20, а умноженный на T в квадрате он остаётся между 0.64 и 0.84 от T = 2 до T = 20 ([урок 3](../lessons/0003-temperature.md)).

## Комбинированная функция потерь

```text
loss = lambda * T^2 * CE(teacher at T, student at T) + (1 - lambda) * CE(label, student at 1)
```

Обозначения принадлежат этому курсу. Hinton и соавторы описывают взвешенное среднее двух кросс-энтропий и обнаружили, что в целом лучшие результаты получаются со значительно меньшим весом кросс-энтропии по жёсткой метке.

| Настройка | Значение | Источник и область |
|---|---|---|
| Речь, относительный вес слагаемого жёсткой метки | 0.5 | Hinton et al., раздел 4.1, одна акустическая модель |
| Речь, проверенные температуры | 1, 2, 5, 10 | Hinton et al., раздел 4.1 |
| MNIST, ученик на 800 блоков, мягкие метки при T = 20 | 74 ошибки на тесте, против 146 без них и 67 у учителя | Hinton et al., раздел 3 |
| MNIST, ученик на 30 блоков, лучшие температуры | от 2.5 до 4 | Hinton et al., раздел 3 |
| Проверенные веса смеси на уровне слов у Kim и Rush | 0.5 и 0.9, лучше 0.5 | Kim and Rush, 2016, раздел 4 |
| Дообучение LLM после прунинга, проверенные температуры | 0.1, 0.5, 1.0, 3.0, лучшая 1.0 | Muralidharan et al., 2024, приложение A.3 |
| Предобучение LLM, проверенные температуры | от 0.5 до 10, лучшая 1 на всех масштабах | Busbridge et al., 2025, приложение G.2 |
| Дообучение LLM после прунинга, смесь потерь | Одна логитная функция потерь лучше смеси с потерей языкового моделирования | Muralidharan et al., 2024, раздел 4 |

Каждая строка это одна статья на собственной постановке. Две строки с температурами для LLM расходятся со строками для классификаторов, так что перебирайте T, включая 1, на вашей собственной паре.

## Токенная функция потерь

| Пункт | Выбор |
|---|---|
| Формы логитов | У ученика и учителя, каждая (batch, positions, vocab) |
| Ось дивергенции | Последняя, по словарю, даёт (batch, positions) |
| Префикс | Фиксированная последовательность, человеческий текст или текст учителя, подаваемая обеим моделям (teacher forcing) |
| Учитель | Прямой проход с отключёнными градиентами |
| Свёртка | Kim и Rush суммируют по позициям. GKD и Minitron делят на длину. Маскируйте паддинг и делите на сумму маски |
| Температура | Делите оба набора логитов на T перед log-softmax, умножайте потерю на T^2, если она смешивается с жёстким слагаемым |

```python
import torch.nn.functional as F

def token_kd_loss(student_logits, teacher_logits, mask, T=1.0):
    s = F.log_softmax(student_logits / T, dim=-1)
    t = F.log_softmax(teacher_logits / T, dim=-1)
    kl = (t.exp() * (t - s)).sum(dim=-1)
    return (kl * mask).sum() / mask.sum()
```

Кросс-энтропия относительно учителя и прямая KL отличаются на энтропию учителя, константу для ученика, так что у них одинаковые градиенты. Gemma 2 записывает сумму -P_T(x | x_c) log P_S(x | x_c) (раздел 3.2).

## Прямая и обратная KL

| | Прямая KL | Обратная KL |
|---|---|---|
| Выражение | KL(p \|\| q) = sum p log(p / q) | KL(q \|\| p) = sum q log(q / p) |
| p это учитель, q ученик | Взвешена по учителю | Взвешена по ученику |
| Что штрафует | Ученика, который даёт малую массу там, где у учителя её много | Ученика, который даёт массу там, где у учителя её мало |
| Поведение | Покрытие мод, растягивается по каждой моде | Поиск моды, выбирает одну |
| На игрушечном примере урока 5 | Предпочитает распределённого ученика, 0.595 против 1.572 | Предпочитает выбравшего ученика, 0.623 против 1.273 |

| Источник | Вывод | Область |
|---|---|---|
| MiniLLM, Gu et al., 2023 | Обратная KL для генеративной дистилляции, поскольку прямая KL отдаёт массу пустым областям учителя | Следование инструкциям, градиент политики на сэмплах ученика |
| GKD, Agarwal et al., 2023 | Лучшая дивергенция зависит от задачи. Обобщённая JSD(beta) интерполирует, похожа на прямую около 0 и на обратную около 1. Обратная KL намного лучше прямой на инструктивной настройке FLAN | Ученики T5, XSum, WMT, GSM8K, FLAN |
| Minitron, Muralidharan et al., 2024 | Лучшая прямая KLD: потеря LM 2.155 против 2.665 у обратной на прунингованной по глубине 8B | Дообучение прунингованных базовых моделей |

`GKDConfig` из TRL выставляет этот выбор как `beta`: 0.0 это KL-дивергенция, 1.0 обратная KL, значение по умолчанию 0.5.

## Ограничение токенизатора

| Ситуация | Что работает | Чего это стоит |
|---|---|---|
| Один токенизатор | Токенная функция потерь | Нужны логиты учителя |
| Ученик построен из учителя (DistilBERT, Minitron) | Токенная функция потерь | Ученик ограничен дизайном учителя |
| Разные токенизаторы, логиты доступны | Функция потерь ULD или тренер GOLD из TRL | Теряется идентичность токена в слагаемом расстояния, допущение единой стоимости, грубое выравнивание позиций |
| Только текст учителя | Обучение на его сгенерированных последовательностях (этап 3) | Ученик никогда не видит распределений учителя |

ULD (Boizard et al., 2024): L = сумма по t от CE(t) + lambda * W1(student, teacher), lambda 1.5, где W1 это сумма абсолютных разностей векторов вероятностей, отсортированных по убыванию (раздел 3). Ученик, ставящий свою массу на неверный токен, может получить 0 по W1, так что сигнал идентичности несёт кросс-энтропия на эталонном токене.

TRL, в том виде, как прочитано для урока 6: `GKDTrainer` принимает один токенизатор как `processing_class` и не имеет аргумента токенизатора учителя. GOLD задокументирован как поддерживающий разные токенизаторы, с `use_uld_loss=True` и `teacher_tokenizer_name_or_path`, и находится в `trl.experimental`.

## Стоимость хранения логитов учителя

Арифметика [урока 7](../lessons/0007-distilling-during-pretraining.md), со словарём Gemma 2 в 256 128 элементов (таблица 1). 2 байта на вероятность и k = 256 с 4-байтовым индексом это допущения, а не цифры из отчёта.

| Величина | Значение |
|---|---|
| Полное распределение на токен, bf16 | 512 256 байт |
| Полное распределение на последовательность из 8 192 токенов | 4.20 ГБ |
| Полное для 2T токенов (запуск 2B) | 1.02 ЭБ |
| Полное для 8T токенов (запуск 9B) | 4.10 ЭБ |
| Top-256 на токен, 6 байт на элемент | 1 536 байт, в 333.5 раза меньше |
| Top-256 для 2T токенов | 3.07 ПБ |
| Top-256 для 8T токенов | 12.29 ПБ |

Отчёт о Gemma 2 не описывает, как распределение учителя поставлялось ученику. Minitron вычисляет учителя в прямом проходе параллельно с обучением и сравнивает запуски при равных вычислениях. Тест top-K у Minitron нашёл значительное падение точности для K до 100 и отсутствие выигрыша от усечения при больших K, на одной постановке дообучения прунингованной модели.
