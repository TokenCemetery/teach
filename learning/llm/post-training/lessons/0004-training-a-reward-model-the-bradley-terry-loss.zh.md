# 第 4 课：训练奖励模型：Bradley-Terry 损失

**使命关联:** “用 Bradley-Terry 损失在偏好对上训练一个奖励模型，并从针对它训练出的策略中，找出一条被奖励破解的补全”是“成功的标准”下的第二条。本课讲训练奖励模型；第 5 课讲针对它优化策略之后可能出什么问题。
**主要来源:** [论文：“Training language models to follow instructions with human feedback”，Ouyang 等，2022](https://arxiv.org/abs/2203.02155)
**前置知识:** [第 3 课](0003-loss-masking-on-non-assistant-tokens.md)

## 热身

1. ▢ 在 SFT 训练中，对非助手 token 做损失掩码，在机制上实际做了什么？

<details markdown="1"><summary>检查</summary>

它给每个提示词或非助手 token 的位置一个损失函数被告知要忽略的标签，所以只有助手（回答）的位置贡献梯度，尽管提示词 token 仍然作为模型据以生成的输入存在。

</details>

2. ▢ 如果跳过这个掩码，SFT 训练会出什么问题？

<details markdown="1"><summary>检查</summary>

梯度信号被花在，或者被稀释在学着预测提示词自己的 token 上，而这不是 SFT 要教的技能，没有完全集中在模型真正该学着生成的回答 token 上。

</details>

## 要点

### 收集偏好数据

奖励模型需要的数据，说的是两个模型输出里哪个更好，而不是最好的输出逐字应该是什么。Ouyang 等人收集这类数据的办法，是给标注员展示针对同一个提示词的若干个输出（他们用 4 到 9 个），让他们对整组输出排序，而不是每次只比较两个。对 `K` 个输出的一次排序，会产生这个排序内的每一个成对比较，共 `K` 取 2 个，所以一次排序任务就能同时产出许多训练对。

### 奖励模型从哪里来

奖励模型不是从一张白纸开始训练的。Ouyang 等人描述的做法，是从 SFT 模型本身出发，去掉它最后的反嵌入层，也就是把隐藏状态变成下一个 token 概率的那一部分，换成一个输出单个标量的层。奖励模型复用了 SFT 模型已经学到的关于语言和目标行为的一切，只是改变了用途：对给定的提示词和补全输出一个数字，即分数，而不是输出下一个 token 的分布。

### Bradley-Terry 损失

对同一个提示词 `x`，给定一条被偏好的补全 `y_w`（“胜者”）和一条被拒绝的补全 `y_l`（“败者”），以及奖励模型对二者各自输出的标量 `r(x, y_w)` 和 `r(x, y_l)`，Ouyang 等人用下面这个损失训练奖励模型：

```text
loss(θ) = -E[log(σ(r_θ(x, y_w) - r_θ(x, y_l)))]
```

其中 `σ` 是 logistic sigmoid 函数。这就是 **Bradley-Terry 损失**：它把人会偏好 `y_w` 胜过 `y_l` 的概率，看作两者分数之差的 sigmoid，并训练奖励模型，使预测出的这个概率与人类标注员实际做出的选择相吻合。把这个损失压低，就意味着把 `r(x, y_w) - r(x, y_l)` 推高：模型被训练成让被偏好的补全的分数，比被拒绝的补全的分数更高，高出的幅度与 sigmoid 需要多有把握地偏向它成正比。

### 为什么奖励的绝对尺度本身没有意义

请注意，这个损失只依赖两个分数的*差*，从不单独依赖任何一个分数。给模型输出的每一个奖励都加上同一个常数，每个差、因而整个损失，都会完全不变。这意味着训练中没有任何东西会把奖励模型的分数强制放到某个特定的绝对尺度上；被约束的只有被偏好与被拒绝的补全之间的相对顺序（以及差距的大小）。Ouyang 等人直接处理了这一点：由于损失对平移是不变的，他们在把奖励模型用于强化学习之前，用一个偏置对它做归一化，使标注员示范的平均得分为 0，给这个原本任意的尺度一个固定的锚点来作衡量。

### 为什么同一次排序产生的比较要放在一起

把一次排序任务产生的 `K` 取 2 个比较，每个都当作独立的、单独打乱的训练样本，会引起一个特定的问题：由于同一小组补全会在其中许多比较里反复出现，在这样构造的数据上只过一遍，就容易过拟合，每条补全实际上在 `K - 1` 个相关的比较中被重复使用。Ouyang 等人的修复办法，是在训练中把来自一次排序任务的所有比较当作一个批次元素，而不是把它们独立地打乱进更大的数据集，他们发现这样比把每个成对比较完全当作独立的，验证准确率和损失都有所改善。

## 练习

1. ▢ 对于一个提示词的一个偏好对，奖励模型输出 `r(x, y_w) = 2.0` 和 `r(x, y_l) = 1.0`；对于另一个提示词的第二个偏好对，输出 `r(x, y_w) = 12.0` 和 `r(x, y_l) = 11.0`。Bradley-Terry 损失会区别对待这两个偏好对吗？

<details markdown="1"><summary>提示</summary>

损失是 `r(x, y_w) - r(x, y_l)` 的函数，而不是其中任何一个值单独的函数。

</details>

<details markdown="1"><summary>检查</summary>

不会。两个偏好对的差相同，都是 `1.0`，而损失只依赖这个差，不依赖绝对分数。这恰恰就是为什么没有外部锚点，奖励模型的绝对尺度就没有意义。

</details>

2. ▢ 按 Ouyang 等人的说法，奖励模型的初始权重实际来自哪里？

<details markdown="1"><summary>检查</summary>

来自 SFT 模型，去掉它最后的反嵌入层，换成一个输出单个标量的层，而不是一个全新的、随机初始化的模型。

</details>

3. ▢ 一位标注员针对单个提示词，对 4 条补全排序（`K = 4`）。这一次排序任务为训练产生多少个成对比较？

<details markdown="1"><summary>检查</summary>

6 个（`4` 取 `2`，即 `(4 × 3) / 2 = 6`）。

</details>

4. ▢ 为什么 Ouyang 等人把来自一次排序任务的所有比较，作为一个批次元素放在一起，而不是把每个成对比较独立地打乱进训练集？

    - a) 这让奖励模型训练得更快，且不影响准确率
    - b) 独立打乱会引起过拟合，因为同一小组补全，在一次排序任务内的许多相关比较中被重复使用
    - c) 除非这样给比较分组，否则无法计算 Bradley-Terry 损失
    - d) 这是为了让奖励模型的分数落在固定的数值范围内，因而是必需的

<details markdown="1"><summary>检查</summary>

**b)** 是 Ouyang 等人直接给出的理由：如果独立打乱，一次排序任务的各个比较中被重复使用且相互相关的补全，会让只过一遍数据就发生过拟合。(a)、(c) 和 (d) 都没有描述真正的问题或它的修复办法。

</details>
