# 第 1 课：预训练语料的来源与混合

**使命关联:** “从原始来源构建一份经过去重和质量过滤的预训练语料，并说清每个过滤步骤删掉了什么、为什么删”是“成功的标准”下的第一条。本课讲其中来源与混合的那一半；第 2 课讲去重和质量过滤。
**主要来源:** [论文：“The Pile: An 800GB Dataset of Diverse Text for Language Modeling”，Gao 等，2020](https://arxiv.org/abs/2101.00027)
**前置知识:** 无

## 要点

### 预训练语料由什么构成

预训练语料，是模型在任何内容被分词之前所训练的那批原始文档的集合：网络爬取的内容、书籍、代码仓库、学术论文、论坛帖子、参考网站等等，它们来自许多彼此独立的来源，而不是从一次巨大的爬取中抓来的。把“语料”当成一堆没有区分的文本，就掩盖了真正决定模型学到什么的那个决定：放进了哪些来源，以及每个来源在最终语料中占多大比例。

### 来源是一个混合的决定，而不只是一个纳入与否的决定

The Pile 是一个有用的演算范例，因为它的作者记录了背后的思考，而不只是把数据集发布出来。它从 22 个多样、高质量的子集中汇集了 825 GiB 的文本，其中许多取自学术或专业来源（法律文件、学术论文、技术文档），这些正是普通网络爬取中占比偏低的内容。论文自己的评测让这一点变得具体：GPT-2 和 GPT-3 都没有在 Pile 上训练过，它们在 Pile 的许多组成部分上表现吃力，“例如学术写作”，而在 Pile 上训练的模型，相比在原始 Common Crawl 或 CC-100 上训练的模型有显著提升，不仅在 Pile 自己的每一个组成部分上如此，在下游评测上也是如此。

这个结果其实不是关于总规模的。它关乎的是哪些领域根本被纳入了，这也是为什么“语料有多大”是评估一次预训练运行时问错了的第一个问题。

### 起杠杆作用的是比例，而不只是有没有

一个来源一旦被纳入，还剩下第二个决定：它能分到最终 token 预算的多少。一个在互联网原始字节数中占主导的来源（论坛闲聊、营销文案、样板式的导航文字），并不自动有权在语料中占主导；而一个原始字节数很小、但信息密度很高的来源（精选的学术文本、参考文档），也不会被困在它自然占有的份额上。语料的设计者可以选择把某些来源相对于其自然规模上采样，把另一些压到远低于自然规模的水平，而这个选择独立于“是否纳入该来源”这个决定，并且是在它之后才做出的。

两份语料可以包含完全相同的来源清单，但如果比例不同，训练之后的表现仍然会不同。这就是为什么“混合”和“来源”是值得分别命名的两个决定，尽管一张数据集名称的表格让它们看起来像是一回事。

### 语料是一件设计出来的产物

来源和混合发生在训练的第一个 token 运行之前，它们的重要性不亚于之后选定的任何一个超参数。在一份组成糟糕的语料上训练的模型，无论预训练运行的后续阶段（第 5 阶段的 ZeRO 分片、第 7 阶段的学习率调度）执行得多好，都会把算力浪费在重新学习冗余或低价值的模式上。那些后续阶段让训练变得高效；而这个阶段决定的是，有什么东西值得被高效地学习。

## 练习

1. ▢ The Pile 从 22 个多样的来源汇集了 825 GiB 的文本，而不是只爬取单个网络爬取源到同样的规模。按论文自己的评测，GPT-2 和 GPT-3（都没有在 Pile 上训练过）在 Pile 的许多组成部分上表现如何？这个结果对只依赖网络爬取的文本说明了什么？

<details markdown="1"><summary>检查</summary>

它们表现吃力，尤其是在学术写作这类组成部分上。这直接证明，主要由通用的网络爬取文本构成的语料，会让模型对整个体裁的接触都很薄弱，不管它见过多少网络文本。

</details>

2. ▢ 一个团队把网络爬取部分的原始字节数翻了一倍，而其他每个来源的字节数保持不变，语料设计上也没有任何其他改动。混合会发生什么变化？

    - a) 混合不变，因为来源只关乎纳入哪些来源，而不关乎每个来源占多少
    - b) 网络爬取在最终语料中的份额增大了，尽管没有人刻意决定让它成为模型所学内容中更大的一部分
    - c) 混合只对分词器如何训练有影响，对模型本身没有影响
    - d) 任何单个来源的规模翻倍，总会提升下游表现

<details markdown="1"><summary>提示</summary>

这里并没有改变存在哪些来源。想一想变化的是每个来源对总量贡献了多少。

</details>

<details markdown="1"><summary>检查</summary>

**b)** 网络爬取的份额会默认增大，这是字节数变化带来的意外副作用，而不是因为有人决定模型应该从它那里学到不成比例地更多的东西。(a) 把纳入和比例混为一谈，而这恰恰是本课要区分的。(c) 是错的：混合塑造的是模型在什么上训练，而不只是词表如何构建。(d) 在一般情况下是错的；低信息量来源的增多，可能稀释语料，而不是改进它。

</details>

3. ▢ 一份新汇集的语料，把一个 2 GB 的精选法律文件小集合，相对于其自然份额重复了好几遍，同时把一个 400 GB 的原始网络爬取部分压到远低于其自然份额。在做这个决定之前，两个来源都已经被选定纳入。这是一个来源的决定还是一个混合的决定，为什么？

<details markdown="1"><summary>检查</summary>

是混合的决定。来源的集合没有变，两者本来就已存在。变化的是每个来源被允许对最终 token 预算贡献多少，这恰好就是本课把它和纳入问题区分开的比例问题。

</details>

## 实战练习

- [ ] 阅读 The Pile 论文中组成来源的清单（见链接论文中的表 1），记下其中你觉得出现在语言模型训练语料里最令人意外的两三项，以及你为什么本来想不到要纳入它们。
- [ ] 找一份你之前没有研究过的、知名的开源预训练语料的公开组成说明（RedPajama、Dolma 和 FineWeb 都有公开的文档）。写下通用的网络爬取文本，与精选或结构化来源，各自大约占多大比例。
- [ ] 明天：为一个你希望在某个特定领域（法律推理、科学文献、某种编程语言）格外出色的模型，草拟一份假想的语料混合。列出你会纳入的四五类来源，并且对每一类，用你自己的话说明你会把它上采样到高于其自然份额、压到低于其自然份额，还是保持原样，以及原因。
