# 学习：量化

拿一个训练好的 LLM，用量化让它更小更快，并清楚每一种数值格式和方法对它的权重、激活值和 KV 缓存做了什么。学完之后，你能针对给定的模型、硬件和质量要求选择一种量化方案，诚实地度量它的代价，并评审别人所说的量化模型“毫无损失”的声明。

**最新课程：** [27. 当惯常答案出错时](lessons/0027-when-the-usual-answer-is-wrong.md)

## 成功的标准

- 读懂一种数值格式的位布局，说出它换来了多大的范围和多高的精度，并算出一个模型在这种格式下占用的内存。
- 手工量化一个张量：选择缩放因子、零点、截断范围和量化粒度，并预测误差会从哪里来。
- 解释为什么 LLM 会有离群特征和离群激活值，以及各自由哪种技术来处理。
- 解释就近舍入、GPTQ 和 AWQ 各自对权重做了什么，以及校准集提供了什么、可能出什么差错。
- 判断什么时候除了权重之外，激活值和 KV 缓存也可以量化，以及用哪种技术。
- 说明量化感知训练在什么时候比训练后量化更值得付出它的成本。
- 预测一种方案在给定硬件和给定批大小下是否真的跑得更快，而不是想当然地认为位数越少就越快。
- 对照一个诚实的基线，度量量化带来的质量代价，而且不止看困惑度。
- 读懂一个量化检查点，无论是带量化配置的 safetensors 还是 GGUF，并说出里面存了什么。
- 针对给定的模型、硬件和质量要求选择一种方案，通过指出度量隐藏了什么来评审别人的量化声明，并说明惯常的答案在什么时候是错的。

## 约束

- 假定你能自如地阅读 Python 和 NumPy，并且知道 Transformer 层大致是“矩阵乘法加注意力”。不需要事先了解量化或浮点数的内部细节。
- 尽可能与硬件无关。凡是某个说法只是某一家厂商或某一个库有文档记载的行为，课程都会点明，因为内核支持的变化比理论快得多。
- 第 1 到第 3 阶段的练习用 NumPy 在笔记本电脑上就能进行。后面的练习会量化一个小型开源模型，一台免费的 GPU 笔记本就够用。

## 范围之外

- QLoRA，也就是穿过 4 位基础模型来训练适配器：见 [`llm/finetuning`](../../llm/finetuning/)，第 4 阶段（第 0014 至 0017 课）。本系列讲的是那些课所应用的一般理论，并链接过去，而不重述 QLoRA。
- 根据服务延迟预算选择方案，并在 vLLM 或 llama.cpp 中运行它：见 [`llm/inference`](../../llm/inference/)，第 3 阶段（第 0007 至 0009 课）及其[服务时量化](../../llm/inference/reference/quantization-at-serve-time.md)参考表。本系列讲的是这些方法如何工作、如何评判它们；服务方面的决定留在那边。
- 搭建评测：见 [`llm/evals`](../../llm/evals/) 及其[上线与否](../../llm/evals/reference/go-no-go.md)参考表。本系列用评测来度量量化损失，不重新讲如何搭建评测。
- 剪枝、稀疏化和蒸馏，也就是缩小模型的其他方法。它们可以与量化结合使用，但属于独立的主题。蒸馏有自己的系列 [`llm/distillation`](../../llm/distillation/)，在它的判断阶段把蒸馏与量化做了比较。
- 编写量化内核。第 7 阶段讲的是一种方案要跑得更快，内核必须做到什么，而不是怎么写内核。

与这两个相邻系列的边界在编写本系列时就已确定：微调和推理的课程保持原样，各自讲它的使用场景所需的那一部分，并链接到这里来补充基础。

## 学习路线

共十个阶段，从数值格式是什么，到评审别人的量化所需的判断力。一个阶段包含若干课程，边界并不严格；一个阶段是否完成，取决于能力，而不是课程数量。

| 阶段 | 课程 | 内容 | 完成的标志 |
|---|---|---|---|
| 1. 数值格式 | 0001 至 0003 | 量化能带来什么，fp32、fp16、bf16、fp8、int8、int4 和块缩放格式 | 能读懂一种格式的位布局，并算出模型在这种格式下的大小 |
| 2. 量化映射 | 0004 至 0006 | 量化与反量化、缩放因子与零点、选择截断范围、逐张量、逐通道和逐组 | 能手工量化一个张量，并预测它的误差 |
| 3. 离群值 | 0007 至 0008 | LLM 中的离群特征和巨大激活值，以及各类修复办法 | 能说清为什么朴素的 int8 LLM 会出问题，以及该用哪种修复办法 |
| 4. 训练后权重量化 | 0009 至 0012 | 就近舍入、GPTQ、AWQ、校准集 | 能把模型的权重量化到 4 位，并解释每种方法改变了什么 |
| 5. 激活值与 KV 缓存 | 0013 至 0016 | 仅权重量化与权重加激活值量化、SmoothQuant、旋转、KV 缓存量化 | 能决定除权重之外还要量化什么，以及用哪种技术 |
| 6. 量化感知训练 | 0017 至 0018 | 伪量化、直通估计器、面向 LLM 的 QAT | 能说清 QAT 在什么时候比训练后量化更值得付出成本 |
| 7. 硬件与内核 | 0019 至 0020 | 受内存带宽限制与受算力限制、内核必须支持什么、哪种硬件运行哪种格式 | 能预测一种方案在给定硬件和批大小下是否跑得更快 |
| 8. 度量质量损失 | 0021 至 0022 | 困惑度及其局限、翻转、任务套件、诚实的对比 | 能度量一次量化的代价，并为这个数字辩护 |
| 9. 文件格式 | 0023 至 0024 | 带量化配置的 Safetensors、GGUF 量化类型与重要性矩阵 | 能读懂一个量化检查点，并说出它存了什么 |
| 10. 判断 | 0025 至 0027 | 选择方案、评审一项声明、发布别人所依赖的量化模型、惯常答案何时出错 | 值得信任去对一次量化做出判断，并向他人解释清楚 |

## 课程

请按顺序学习。

| # | 课程 | 内容 |
|---|---|---|
| [0001](lessons/0001-what-quantization-buys.md) | 量化能带来什么 | 每个参数的位数越少，内存和每个 token 读取的字节数就越少，而大部分速度提升正来自后者 |
| [0002](lessons/0002-floating-point-formats.md) | 浮点格式 | 在 fp32、fp16 和 bf16 中，符号位、指数位和尾数位如何把范围与精度分开 |
| [0003](lessons/0003-low-bit-formats.md) | 低位格式 | fp8、int8、int4 以及 MXFP4 这类块缩放格式能表示什么、不能表示什么 |
| [0004](lessons/0004-quantize-and-dequantize.md) | 量化与反量化 | 从实数值到整数的仿射映射：缩放因子、零点、舍入与钳制 |
| [0005](lessons/0005-choosing-the-range.md) | 选择范围 | 为什么截断范围是拿少量的截断误差，换来少得多的舍入误差 |
| [0006](lessons/0006-granularity.md) | 量化粒度 | 逐张量、逐通道和逐组的缩放因子，以及各自在存储位数上的代价 |
| [0007](lessons/0007-why-llms-have-outliers.md) | LLM 为什么有离群值 | 离群特征维度和巨大激活值出现在哪里，以及为什么一个值就能毁掉整个张量的缩放因子 |
| [0008](lessons/0008-handling-outliers.md) | 处理离群值 | 四类修复办法：把它们保留在高精度、缩小分组、迁移它们，或者把它们旋转掉 |
| [0009](lessons/0009-round-to-nearest.md) | 就近舍入 | 不用任何数据、逐个量化权重，为什么它在 8 位时站得住，在 4 位或更少时就不行了 |
| [0010](lessons/0010-gptq.md) | GPTQ | 依次量化一层的权重，并把每一次舍入误差花在尚未量化的权重上 |
| [0011](lessons/0011-awq.md) | AWQ | 在舍入之前先缩放通道，来保护那些遇到大激活值的权重 |
| [0012](lessons/0012-the-calibration-set.md) | 校准集 | 一种方法会读取什么校准数据、需要多少，以及不匹配的校准集会如何暴露出来 |
| [0013](lessons/0013-weights-activations-or-both.md) | 权重、激活值，还是两者兼顾 | 仅权重量化与权重加激活值量化各自省下什么，以及为什么激活值更难 |
| [0014](lessons/0014-smoothquant.md) | SmoothQuant | 用逐通道的缩放因子，把量化的难度从激活值转移到权重上 |
| [0015](lessons/0015-rotations.md) | 旋转 | 乘以一个正交矩阵，把离群值分散到各个通道上，使 4 位激活值得以保住 |
| [0016](lessons/0016-kv-cache-quantization.md) | KV 缓存量化 | 为什么键和值要沿不同的轴量化，以及它在长上下文下换来什么 |
| [0017](lessons/0017-fake-quantization-and-the-ste.md) | 伪量化与 STE | 训练如何感知量化：前向传播中的模拟舍入，反向传播中的直通梯度 |
| [0018](lessons/0018-qat-for-llms.md) | 面向 LLM 的 QAT | 量化感知训练用在 LLM 上要付出什么代价、能挽回什么，以及什么时候训练后量化就够了 |
| [0019](lessons/0019-what-actually-runs-faster.md) | 什么才真正跑得更快 | 为什么仅权重量化能加快小批量解码，却可能拖慢大批量预填充 |
| [0020](lessons/0020-hardware-and-kernel-support.md) | 硬件与内核支持 | GPU 原生计算哪些格式、只存储哪些格式，以及缺少内核要付出什么代价 |
| [0021](lessons/0021-perplexity-and-its-limits.md) | 困惑度及其局限 | 困惑度度量什么，为什么很小的变化也可能掩盖大量答案翻转，以及改为度量什么 |
| [0022](lessons/0022-an-honest-quantization-eval.md) | 一份诚实的量化评测 | 在同一套测评框架和任务上，把量化模型与它的基线做比较，并报告它丢掉了什么、丢在哪里 |
| [0023](lessons/0023-quantized-checkpoints.md) | 量化检查点 | 量化的 safetensors 检查点存了什么，以及它的量化配置如何告诉加载器怎样去读它 |
| [0024](lessons/0024-gguf-quant-types.md) | GGUF 量化类型 | 像 Q4_K_M 这样的 GGUF 类型名是什么意思，以及重要性矩阵改变了什么 |
| [0025](lessons/0025-choosing-a-scheme.md) | 选择方案 | 根据模型、硬件、批的形态和质量要求来选定格式与方法 |
| [0026](lessons/0026-reviewing-a-quantization-claim.md) | 评审一项量化声明 | 通过指出度量隐藏了什么，来评审“4 位且无质量损失”，并上线别人所依赖的量化模型 |
| [0027](lessons/0027-when-the-usual-answer-is-wrong.md) | 当惯常答案出错时 | 识别 4 位权重或标准做法在什么时候是错误的决定，并从一手来源来裁定争议 |

## 使用方式

每节课都简短且自成一体。答案默认折叠：先自己回忆，再展开查看。真实场景中的练习比阅读更重要，而把练习间隔开来正是关键。课程结束时仍不清楚的地方，值得先追溯到一手资料再继续往下学。
