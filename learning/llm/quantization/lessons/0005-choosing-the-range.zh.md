# 第 5 课：选择范围

**使命关联:** 要预测一个量化误差来自哪里，就得知道某个截断范围会让它的两部分中的哪一部分变大，而范围正是把误差在这两部分之间转移的那个选择。
**主要来源:** [论文：“A White Paper on Neural Network Quantization”，Nagel 等，2021](https://arxiv.org/abs/2106.08295)，第 3.1 节
**前置知识:** [第 4 课](0004-quantize-and-dequantize.md)、[截断范围](../GLOSSARY.md)、[截断误差](../GLOSSARY.md)、[舍入误差](../GLOSSARY.md)

## 热身

1. ▢ 一个 4 位仿射量化器覆盖 -1 到 3 的范围。它的步长和最大舍入误差各是多少？

<details markdown="1"><summary>检查</summary>

步长是 `s = 4 / 15 = 0.267`，最大舍入误差是 `s/2 = 0.133`。范围被分成 2^4 - 1 = 15 步，范围之内的值最多移动半个步长。

</details>

2. ▢ 一个值落在量化器的网格界限之外。它的误差是否以 `s/2` 为界？这个误差叫什么？

<details markdown="1"><summary>检查</summary>

不是。这个值被钳制到最近的网格界限，它移动的距离就是**截断误差**，它没有 `s/2` 这个界，而且随着这个值落在范围之外多远而增大。

</details>

3. ▢ 为什么量化器通常把对称的权重与非对称的激活值搭配使用？

<details markdown="1"><summary>检查</summary>

非对称权重乘以非对称激活值，会产生一个取决于输入数据的项，这在运行时要付出延迟和功耗的代价（Nagel 等，第 2.4.1 节）。对称的权重网格去掉了这一项，所以只有激活值保留了额外的零点。

</details>

## 要点

### 两种方向相反的误差

**截断范围**是整数网格所覆盖的那段实数区间，从 `q_min` 到 `q_max`。Nagel 等人在第 2.2 节用一句话说清了整个权衡：放宽范围会减少截断误差，但需要更大的缩放因子，而位于 -s/2 到 s/2 之间的舍入误差也随之增大。

| 范围 | 截断误差 | 舍入误差 | 出什么问题 |
|---|---|---|---|
| 太窄 | 大：离群值被钳制 | 小 | 最大的值被范围的边缘取代 |
| 太宽 | 无 | 大：步长很大 | 典型的值落进寥寥几个档位，或者舍入成零 |

论文第 3.1 节称这是设定范围时的关键权衡，并说每种方法在这两种误差之间给出的平衡各不相同。权重是事先已知的，所以它们的范围通常不需要数据。激活值的范围取决于输入，所以 Nagel 等人说它通常需要几批校准数据，这就是[校准集](../GLOSSARY.md)的任务。

### 各种方法

**最小最大值法**。取最小值和最大值作为 `q_min` 和 `q_max`。它没有截断误差，Nagel 等人警告说它对离群值敏感，因为一个强烈的离群值会迫使步长变大，从而造成过度的舍入误差。第 4 课用的就是它。

**均方误差法**。搜索使原始张量与量化后张量之间均方误差最小的 `q_min` 和 `q_max`。论文列出了网格搜索、黄金分割法和闭式近似作为求解方式，并说文献中的各种变体都非常相似。当离群值把最小最大值范围撑大时，就该选这种方法。

**百分位数法**。把范围设为绝对值的某个高百分位数，例如第 99.9 个，使固定比例的值被截断。这是一个简单的启发式做法，不是第 3.1 节中的方法之一，下面的实验用了它，好让你看清固定比例的截断要花什么、能换回什么。

第 3.1 节还列出了两种用于特殊情形的方法：对最后一层的 logit 最小化交叉熵，因为那里最大几个值的顺序，比许许多多小值更重要；以及对激活值使用基于批归一化的范围。本系列量化的是没有批归一化的 LLM，所以用的是前三种。

Nagel 等人在他们的表 1 中，在 ImageNet 分类器上比较了前两种方法，权重按逐张量量化，激活值保持浮点。对 ResNet18，8 位时最小最大值法和 MSE 法大致持平：top-1 准确率分别为 69.57 和 69.45。到了 4 位，最小最大值法跌到 0.12，而 MSE 法保住了 18.82。这些是视觉模型，所以请读它的结果形态，而不是数字本身：档位很少时，范围的选择决定了模型到底能不能工作。

### 实验显示了什么

练习里的实验把一个重尾张量量化到 4 位。它的最大值是 1.506，标准差是 0.034，比值约为 44。用最小最大值范围，步长是 `1.506 / 7 = 0.215`，它的一半是 0.108，超过三个标准差，所以几乎每个值都舍入成零。把 MSE 搜索所截断的那 0.35% 的值截断掉，误差降低到约六分之一。网格被花在了一个几乎没有值会光顾的范围上。

### 为什么这对 LLM 来说还不是完整的答案

MSE 对每个值的平方误差一视同仁。Nagel 等人对 logit 也说过同样的话：MSE 可能不适合重要性不均等的值，因为它给所有值同样的权重。在 LLM 中，最大的那几个值可能恰恰是重要的。[Dettmers 等人](https://arxiv.org/abs/2208.07339)报告说，把离群特征维度置零，会使验证集困惑度恶化 600% 到 1000%，尽管它们只占特征的约 0.1%。一个把它们截断的范围，对张量的 MSE 影响微乎其微，对模型的影响却可能很大。第 7 课解释这些值从何而来，第 8 课给出不截断它们的修复办法。

## 练习

1. ▢ 一个 4 位有符号对称量化器，网格为 -7 到 7，在一个标准差为 0.034 的张量上，最小最大值范围是 1.506。`s` 是多少？哪些值会舍入成零？

<details markdown="1"><summary>检查</summary>

`s = 1.506 / 7 = 0.215`。绝对值小于 `s/2 = 0.108` 的任何值，都舍入成整数 0，这超过了三个标准差。对一个钟形分布的张量，这就是几乎每一个值，所以一个遥远的最大值就把整个张量抹掉了。

</details>

2. ▢ 下面哪一种说法描述的是放宽截断范围？

    - a) 截断误差和舍入误差都下降
    - b) 截断误差和舍入误差都上升
    - c) 截断误差下降，舍入误差上升
    - d) 截断误差上升，舍入误差下降

<details markdown="1"><summary>检查</summary>

**c)** 更宽的范围钳制的值更少，所以截断误差下降，但同样数目的档位现在要跨越更远的距离，所以步长和舍入误差增大。(a) 会让范围的选择变得毫无难度，因为你总是放宽就行了。(b) 两个都说错了，因为放宽不可能让截断误差上升。(d) 描述的是收窄范围，而不是放宽。

</details>

3. ▢ 先预测，再运行。这段代码在四种范围下，把 100,000 个重尾的值量化到 4 位。运行之前，先预测哪种范围的均方误差最低，以及最小最大值法是否把一半以上的值舍入成零。

    ```python
    import numpy as np

    rng = np.random.default_rng(0)
    x = rng.standard_t(df=3, size=100_000) * 0.02   # heavy-tailed
    qmax = 7                                        # 4-bit signed symmetric grid: -7..7 times the scale


    def quantize(x, c):
        s = c / qmax
        return s * np.clip(np.round(x / s), -qmax, qmax)


    def mse(x, c):
        return np.mean((quantize(x, c) - x) ** 2)


    grid = np.linspace(0.01, np.abs(x).max(), 400)
    ranges = {
        "min-max": np.abs(x).max(),
        "p99.9": np.percentile(np.abs(x), 99.9),
        "p99": np.percentile(np.abs(x), 99),
        "MSE search": grid[np.argmin([mse(x, c) for c in grid])],
    }
    print("max |x| =", round(np.abs(x).max(), 3), " std =", round(x.std(), 3))
    for name, c in ranges.items():
        q = quantize(x, c)
        print(f"{name:10s} c={c:.3f}  mse={mse(x, c):.2e}  clipped={np.mean(np.abs(x) > c):6.2%}  rounded to zero={np.mean(q == 0):6.2%}")
    ```

<details markdown="1"><summary>提示</summary>

先像第 1 题那样算出最小最大值法的步长，再把它的一半与标准差比较。

</details>

<details markdown="1"><summary>检查</summary>

```text
max |x| = 1.506  std = 0.034
min-max    c=1.506  mse=8.15e-04  clipped= 0.00%  rounded to zero=98.72%
p99.9      c=0.252  mse=1.61e-04  clipped= 0.10%  rounded to zero=56.61%
p99        c=0.117  mse=1.53e-04  clipped= 1.00%  rounded to zero=29.40%
MSE search c=0.171  mse=1.35e-04  clipped= 0.35%  rounded to zero=41.52%
```

MSE 搜索胜出，最小最大值法最差，高出约六倍，98.7% 的值被舍入成零。只截断 0.10% 的值（p99.9），误差就已经降到了五分之一。截断 1%（p99）比搜索的结果略差（1.53e-04 对 1.35e-04），因为被截断的那些值现在的代价超过了舍入省下的：最佳范围位于两个极端之间。

</details>

4. ▢ 先预测，再运行。把 `qmax = 7` 改成 `qmax = 127`，使它成为 8 位网格，重新运行。截断还会胜出吗？MSE 搜索现在选择什么范围？

<details markdown="1"><summary>检查</summary>

```text
max |x| = 1.506  std = 0.034
min-max    c=1.506  mse=1.17e-05  clipped= 0.00%  rounded to zero=21.23%
p99.9      c=0.252  mse=5.51e-05  clipped= 0.10%  rounded to zero= 3.65%
p99        c=0.117  mse=1.30e-04  clipped= 1.00%  rounded to zero= 1.69%
MSE search c=1.019  mse=7.72e-06  clipped= 0.00%  rounded to zero=14.52%
```

截断不再胜出：最小最大值法胜过两种百分位数范围，MSE 搜索选择了 1.019，接近完整的范围，被截断的值不到 0.005%。每侧有 127 个档位，步长已经小到离群值带来的舍入误差很小，而把它们截断的代价却很大。这与 Nagel 等人表 1 的形态相同，那里最小最大值法和 MSE 法在 8 位时持平：档位越少，收紧范围越划算。

</details>

5. ▢ 一个团队通过最小化 MSE 来设定每个 LLM 激活值的范围，结果困惑度飙升。请用这一课的内容，给出最可能的机制，并说明 MSE 没能看到什么。

<details markdown="1"><summary>检查</summary>

这个范围把离群特征截断了。它们只占值的很小一部分，所以钳制它们对张量 MSE 的改变很小，但它们的重要性远超它们的数量：Dettmers 等人度量到，把这些维度置零时，困惑度高出 600% 到 1000%。MSE 对每个值一视同仁，Nagel 等人指出，当各个值的重要性不同时，这是错误的加权。设定范围的目标，是任务损失的一个局部代理，而这里它指错了方向。让离群值不被截断，是第 8 课的主题。

</details>
