# 数值格式：布局、范围、精度与内存

把第 1 阶段压缩成便于查阅的形式。[第 1 课](../lessons/0001-what-quantization-buys.md)讲量化能带来什么和内存的算法，[第 2 课](../lessons/0002-floating-point-formats.md)讲浮点格式 fp32、fp16 和 bf16，[第 3 课](../lessons/0003-low-bit-formats.md)讲 fp8、int8、int4 和块缩放格式。

## 读懂浮点布局

```text
value = (-1)^sign × 2^(e - bias) × (1 + m / 2^M)
```

- `e` 是指数字段，`m` 是尾数字段，`M` 是尾数位数。
- 指数字段全为 0：零和非规格化值，`(m / 2^M) × 2^(1 - bias)`。
- 指数字段全为 1：在 IEEE 格式中是无穷大和 NaN。E4M3 是例外，它把这一档用于普通的值。
- 指数位决定范围。尾数位决定精度。机器精度是 `2^-M`。
- 在 `2^k` 与 `2^(k+1)` 之间，相邻的值相隔 `2^(k-M)`：间隔在每个 2 的幂处翻倍。

## 浮点格式

|格式|位数|符号 / 指数 / 尾数|偏置|最大有限值|最小规格化值|机器精度|
|---|---|---|---|---|---|---|
|fp32|32|1 / 8 / 23|127|3.4 × 10^38|1.2 × 10^-38|2^-23，约 1.2 × 10^-7|
|fp16|16|1 / 5 / 10|15|65,504|6.1 × 10^-5|2^-10，约 9.8 × 10^-4|
|bf16|16|1 / 8 / 7|127|3.4 × 10^38|1.2 × 10^-38|2^-7，约 7.8 × 10^-3|
|fp8 E4M3|8|1 / 4 / 3|7|448|2^-6|2^-3|
|fp8 E5M2|8|1 / 5 / 2|15|57,344|2^-14|2^-2|
|FP4 E2M1|4|1 / 2 / 1|1|6|1|2^-1|

- fp16 的最小非规格化值是 `2^-24`。比它更小的值变成零。
- E4M3 的最小非规格化值是 `2^-9`，E5M2 是 `2^-16`。
- E4M3 没有无穷大，只有一种 NaN 模式（S.1111.111）。E5M2 遵循 IEEE，有无穷大和 NaN。
- bf16 就是去掉低 16 位的 fp32。
- E4M3、E5M2 和 fp16 这几行来自各课的来源。FP4 E2M1 这一行由它的布局和第 3 课用的偏置 1 推导而来。fp8 和 FP4 各行的机器精度，按同样的规则是 `2^-M`。

## 什么格式用在什么地方

|格式|出现在|原因|
|---|---|---|
|fp32|基线，以及混合精度中的累加|范围宽、间隔细，4 字节|
|fp16|带损失缩放的混合精度训练|间隔细、范围窄：训练需要损失缩放|
|bf16|不带损失缩放的训练|有 fp32 的范围，所以不需要损失缩放，尾数粗|
|E4M3|权重和激活值|间隔更细，范围到 448|
|E5M2|梯度|范围更宽，间隔粗|

## 整数网格

|格式|档位数|范围|间隔|
|---|---|---|---|
|int8|256|-128 到 127|处处为 1|
|int4|16|-8 到 7|处处为 1|

- 值是 `scale × integer`。没有缩放因子，整数网格只能装下整数。
- 浮点网格自带范围，需要一个缩放因子来安放它。整数网格的整个范围都来自缩放因子。
- 小于半个步长的值会舍入成零，不管有没有缩放因子。

## 块缩放格式

|格式|块大小|缩放因子|元素|元素位数|每个权重的有效位数|
|---|---|---|---|---|---|
|MXFP8|32|E8M0|E4M3 或 E5M2|8|8.25|
|MXFP6|32|E8M0|E2M3 或 E3M2|6|6.25|
|MXFP4|32|E8M0|E2M1|4|4.25|
|MXINT8|32|E8M0|int8|8|8.25|
|NVFP4|16|E4M3，外加每个张量一个 FP32 缩放因子|E2M1|4|4.5，忽略逐张量的标量|

- 每个元素的值是 `X × P`：共用的缩放因子乘以所存的元素。
- E8M0 只有指数，所以 MX 的缩放因子永远是 2 的幂。NVFP4 中 E4M3 的缩放因子可以是分数倍。
- E2M1 的正值：0、0.5、1、1.5、2、3、4、6。
- 一个块里的一个大值，决定整个块的缩放因子，并可能把它的邻居舍入成零。
- NVFP4 的细节来自 NVIDIA 自己的博客文章，那是厂商文档。

## 内存的算法

以 GB 计的权重内存是 `以十亿计的参数量 × 每个权重的有效位数 / 8`。每个权重的有效位数是位宽加上缩放因子的位数除以分组或块的大小。

|格式|有效位数|8B 模型|70B 模型|
|---|---|---|---|
|fp32|32|32 GB|280 GB|
|fp16 或 bf16|16|16 GB|140 GB|
|fp8 或 int8|8|8 GB|70 GB|
|MXFP4|4.25|4.25 GB|约 37.2 GB|
|NVFP4|4.5|4.5 GB|约 39.4 GB|
|int4，每 128 个一个 16 位缩放因子|4.125|4.125 GB|约 36.1 GB|
|int4，每 32 个一个 16 位缩放因子|4.5|4.5 GB|约 39.4 GB|

- 这些只是权重。KV 缓存和激活值要另外加。
- 缩放因子的开销：`scale bits / group size`。每 128 个权重一个 16 位缩放因子，增加 0.125 位，每 32 个则增加 0.5 位。
