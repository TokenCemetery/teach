# 权重训练后量化方法：就近舍入、GPTQ 与 AWQ 的对比

把第 4 阶段压缩成便于查阅的形式。[第 9 课](../lessons/0009-round-to-nearest.md)讲就近舍入（RTN），[第 10 课](../lessons/0010-gptq.md)讲 GPTQ，[第 11 课](../lessons/0011-awq.md)讲 AWQ，[第 12 课](../lessons/0012-the-calibration-set.md)讲校准集。

## 三种方法并排对比

| | 就近舍入 | GPTQ | AWQ |
|---|---|---|---|
| 思路 | 把每个权重舍入到离它最近的档位 | 依次对各列做舍入，把每次误差推到尚未舍入的列上 | 在舍入之前把显著的输入通道放大，并把激活值除以同样的缩放因子 |
| 从数据读取 | 什么都不读 | 各层输入，累加成 `H = 2 X X^T` | 每个通道的平均激活值幅值，加上用来给每个 `alpha` 打分的各层输出 |
| 是否改变权重的值 | 否 | 是，每次舍入之后改变后面的每一列 | 是，通过逐通道缩放因子 `s = s_X^alpha`，然后做就近舍入 |
| 目标 | 每个权重自己的误差 | 每层的 `argmin \|\| W X - Ŵ X \|\|^2` | 同样的层输出误差，在 [0, 1] 内对 `alpha` 做搜索 |
| 反向传播 | 无 | 无 | 无 |
| 成本 | 可以忽略 | 175B 参数约 4 个 GPU 小时（论文） | 每层对 `alpha` 的 20 个取值做网格搜索（论文） |
| 网格 | 每行或每组一个缩放因子 | 循环开始前固定；逐组的缩放因子在循环走到该组时确定 | 逐组，论文中是 128 |
| 主要风险 | 用逐行缩放因子，在 3 位时崩溃 | 在小的或不匹配的校准集上过拟合 | 缩放得太狠，会损害非显著通道 |

## 各自对数字做了什么

| WikiText-2 困惑度 | 16 位 | RTN | GPTQ | AWQ |
|---|---|---|---|---|
| OPT-175B，4 位，逐行网格 | 8.34 | 10.54 | 8.37 | 那里没有报告 |
| OPT-175B，3 位，逐行网格 | 8.34 | 7,300 | 8.68 | 那里没有报告 |
| Llama-2 7B，4 位，以 128 为一组 | 5.47 | 5.73 | 5.69 | 5.60 |
| Llama-2 7B，3 位，以 128 为一组 | 5.47 | 6.66 | 6.43 | 6.24 |

前两行来自 GPTQ 论文，后两行来自 AWQ 论文。网格和模型都不同，所以请在一行之内做比较，比较各行之间的形态，而不是跨行比较数字。每篇论文都是拿自己的方法去对照另一个方法来评测的，所以请把这些差距读作作者自己的运行结果。

## 误差为什么是这样的表现

| 事实 | 结论 |
|---|---|
| 每去掉一位，步长大致翻倍 | 就近舍入的误差每位大致翻倍 |
| 在第 9 课的玩具例子里，误差之比等于步长之比：从 8 位到 4 位是 127 / 7 = 18.1，从 4 位到 3 位是 7 / 3 = 2.3 | 最后几位是最贵的 |
| 就近舍入把每个权重的误差降到最小，而不是层输出的误差 | 在一个相关的玩具层上，2000 次随机舍入中有 919 次胜过它 |
| GPTQ 的收益来自相关的输入 | 输入相互独立时它几乎消失（玩具例子里是 0.2680 对 0.2595） |
| 显著权重是按激活值而不是按大小来挑选的 | 在 3 位的 OPT-6.7B 上，按激活值选 1% 得 11.39，按权重大小选得 22.37，普通就近舍入是 23.54 |
| 把一个通道缩放 `s`，它的相对误差缩小约 `1 / s` | `s` 太大会提高同组其他通道的步长 |

## GPTQ 的三个扩展性改动与 act-order

| 改动 | 修复了什么 |
|---|---|
| 每一行用同样的列顺序 | 每一列做一次逆的更新，就能服务所有行 |
| 惰性批量更新，一次 128 列 | 更新受内存带宽限制，所以把它做成批能用上 GPU |
| 取平均对角线 1% 的阻尼，外加一个 Cholesky 因子 | 可能让逆矩阵变成不定的数值误差 |
| Act-order（作者的代码里有，论文里没有）：按 `H` 的对角线把各列从大到小排序 | 修复糟糕的结果，例如 3 位的 OPT-66B（14.16 到 9.95）；除非使用静态分组，否则可能需要改动推理 |

## 校准集的作用

| | GPTQ | AWQ |
|---|---|---|
| 典型大小 | 论文：来自 C4 的 128 个 2048 token 的片段 | 在 3 位的 OPT-6.7B 上，AWQ 用 16 条序列胜过 GPTQ 用 192 条（作者的运行） |
| llm-compressor | 典型为 128 到 512 个样本，从 128 到 256 个开始 | 同样的建议；它的示例用 256 个 |
| 需要更多数据，因为 | 它估计的是特征如何共同变化的一整个矩阵 | 它估计的是每个通道的一个均值 |
| 不匹配的惩罚，OPT-6.7B，3 位（AWQ 论文） | 困惑度差 2.3 到 4.9 | 差 0.5 到 0.6 |

- 就近舍入不需要数据。GPTQ 和 AWQ 需要校准集。两者都不会对它做反向传播。
- 校准集不是训练数据，它的领域会体现在结果里。
- 让校准集匹配目标用途：通用模型用通用文本，指令模型用指令数据，代码模型用代码（llm-compressor）。
- 在校准领域留出的文本上，以及你所服务的其他领域的文本上做评测。在一个上有收益，在另一个上有损失，就是不匹配。
- 在抽取校准集的那段文本上度量到的困惑度，是被抬高了的。GPTQ 论文说，它在 C4 上的结果因为这个原因并非完全零样本。
- 在第 12 课的玩具例子里，样本太少（128 个特征只有 64 个样本），使 GPTQ 即使在领域内也比就近舍入差。

## 在信任一个权重训练后量化检查点之前

- 哪种方法，哪种位宽，以及哪种分组大小或网格。
- 哪个校准集，多少个样本，多长。如果模型卡没有说，那就是一个缺口。
- 引用的困惑度是否是在校准领域上度量的。
- 是否在同一个评测上，度量过同样网格下不需要数据的基线。
- 对带 act-order 和分组的 GPTQ，它是否需要改动推理，因而可能损失速度，或者是否是用静态分组做的。
