# Transformer 术语表

Transformer 架构的规范术语，都是从原始张量推导出来的，而不是来自现成的模块。

## 术语

**交叉注意力（Cross-attention）**:
一种注意力子层，它的查询来自一个序列（解码器到目前为止自己生成的输出），而键和值来自另一个序列（独立编码器的输出），让解码器在生成时可以查阅完整的、已经编码好的输入。仅解码器模型里没有这种子层，因为它既没有独立的编码器，也没有可以跨越去关注的输入序列。
_避免使用_: 自注意力（self-attention，那是另一种子层，它的查询、键和值都来自同一个序列；交叉注意力的键和值则专门取自与查询不同的序列）

**编码器-解码器（Encoder-decoder）**:
一种架构（如原始 Transformer 论文或 T5），把一个双向编码器与一个解码器配成一对：编码器没有因果掩码，处理完整的输入；解码器用因果自注意力，再加上回看编码器输出的交叉注意力，以自回归方式生成输出。适合输入与输出泾渭分明的任务，比如翻译。
_避免使用_: 仅解码器（decoder-only，本工作区搭建的架构，没有独立的编码器，也没有交叉注意力，因为它的单一数据流既充当条件上下文，也充当生成出来的输出）

**仅编码器（Encoder-only）**:
一种使用双向注意力的架构（如 BERT），每一层都同时以左侧和右侧的上下文为条件，完全没有因果掩码。它为一段完整的、已经给定的输入构建表示，服务于理解类任务（分类、抽取），而不是以自回归方式生成文本，这是它的架构做不到的事。
_避免使用_: 仅解码器（decoder-only，一种带因果掩码、专门用来一次生成一个 token 的架构；仅编码器的双向注意力从未被训练成只凭前缀去预测）

**FlashAttention**:
缩放点积注意力的一种感知 IO 的精确实现，它把计算分块，使其始终留在快速的片上 GPU 内存（SRAM）中，永远不在较慢的主内存（HBM）里实体化那个完整的、规模呈二次方增长的注意力分数矩阵。它算出的数学结果与第 1 课的方程完全相同；提速完全来自内存访问，而不是来自对任何东西的近似。
_避免使用_: 近似注意力（approximate attention，那是另一类用质量换速度的方法；FlashAttention 是精确的，它的提速纯粹来自 IO 效率）

**门控线性单元（Gated linear unit，GLU）**:
同一个输入的两个线性投影的逐元素乘积，其中一个先经过非线性（最初是 sigmoid）。那个投影充当门，逐个元素地缩放另一个投影的输出，而不是对所有元素统一施加一个固定的非线性。
_避免使用_: SwiGLU（那是 GLU 的一个具体变体，用 Swish/SiLU 做门控；“GLU”是整个家族的统称，不是其中某一个成员）

**梯度累积（Gradient accumulation）**:
依次在几个较小的微批次上运行前向和反向传播，期间不把梯度清零，让每个微批次的梯度叠加到之前的梯度上，然后用合并后的总梯度让优化器只走一步。它模拟出一个比内存一次能容纳的更大的有效批大小，而不改变所计算的内容。
_避免使用_: 增大实际的批大小（increasing the actual batch size，那是梯度累积要达到的目标，而它做到这一点，并不需要那个更大的批次曾同时装进内存）

**梯度范数裁剪（Gradient norm clipping）**:
只要整个梯度向量的范数会超过选定的阈值，就把它整体按比例缩小，使范数不超过阈值，方向保持不变。它防止偶尔出现的梯度爆炸造成一次破坏性的巨大更新。
_避免使用_: 对每个参数的梯度分别裁剪（clipping each parameter's gradient independently，这会扭曲合并后梯度的方向；基于范数的裁剪则是对整个向量统一缩放）

**贪心解码（Greedy decoding）**:
在每一步生成时，总是从模型预测的分布里选出概率最高的那一个 token。它是确定性的；尽管它最大化的正是模型被训练去预测好的那个量，实际产生的文本却平淡无奇，还会奇怪地重复。
_避免使用_: 认为训练目标（似然）自动就是正确的解码目标（assuming the training objective (likelihood) is automatically the right decoding objective；这是两个不同的问题，答案也不同）

**分组查询注意力（Grouped-query attention，GQA）**:
一种注意力变体，使用居中数量的键/值头，多于一个，少于查询头的数量，每组查询头共用一个键/值头。它介于完整多头注意力的每头各自一套键/值与多查询注意力的单个共享头之间，是一种折中。
_避免使用_: 多查询注意力（multi-query attention，MQA，那是更极端的情形，只有一个共享的键/值头；GQA 是保留多于一个键/值头的推广）

**KV 缓存（KV cache）**:
自回归生成期间，保存之前每个位置的键向量和值向量，在每个新的生成步骤里复用，而不是从头重新计算。它的大小随模型拥有的不同键/值头集合的数量而增长，而分组查询注意力和多查询注意力减少的正是这一点。
_避免使用_: 在每个生成步骤都重新计算键和值（recomputing keys and values at every generation step，结果正确但浪费；缓存正是为了避免这件事才存在的）

**学习率预热（Learning rate warmup）**:
在最初固定的若干训练步里，让学习率逐渐上升（通常是线性上升）直到目标值，而不是一开始就全力施加。它针对的是 Adam 的矩估计在最初几步不可靠：当时见过的梯度太少，还不足以校准它们。
_避免使用_: 从第一步起就使用目标学习率（applying the target learning rate from step one，在优化器自身的统计量稳定下来之前，有可能造成一次巨大而方向不佳的更新）

**混合精度训练（Mixed precision training）**:
训练的大部分时间里，用半精度而不是全（单）精度存储权重、激活值和梯度，把内存占用削减近一半。这需要一份全精度的主权重副本（用来保留否则会下溢的微小更新），以及损失缩放（防止微小的梯度下溢为零）。
_避免使用_: 只用半精度训练、既没有主权重副本也没有损失缩放（training in half precision alone, with no master weight copy or loss scaling，有可能悄无声息地因下溢丢掉微小的更新和梯度）

**混合专家（Mixture-of-experts，MoE）**:
一种层，用若干并行的专家前馈块，加上一个决定由哪些专家处理某个 token 的路由器，来取代单个前馈块。它是稀疏激活的：总参数量随专家数量增长，但每个 token 的计算成本大致不变，因为真正运行的只有被选中的专家。
_避免使用_: 认为专家越多，每个 token 的计算就越多（assuming more experts means more compute per token，不论总共有多少个专家，只有路由器为某个 token 选中的专家的计算，才计入该 token 的成本）

**核采样（Nucleus sampling，top-p）**:
从累积概率超过阈值 `p` 的最小高概率 token 集合中采样，这个集合的大小随每一步分布是尖峰还是平坦而变化。与之对照的是 top-k 的固定大小截断，它无法适应这种变化。
_避免使用_: top-k 采样（top-k sampling，那是固定个数的截断；核采样的截断点则是基于累积概率、大小动态变化的集合）

**RMSNorm**:
一种归一化，用激活向量的均方根去除它，再施加一个学习得到的缩放，保留了层归一化的重新缩放运算，而把它的重新中心化（减去均值）这一步完全去掉。它比层归一化更便宜，实际任务表现相当。
_避免使用_: 层归一化（layer norm，那是 RMSNorm 所简化的基于均值和方差的归一化；RMSNorm 根本不计算也不减去均值）

**旋转位置嵌入（Rotary position embedding，RoPE）**:
一种位置机制，它把投影后的查询向量和键向量按与其位置成正比的角度旋转，而不是事先给嵌入加上一个固定向量。由于旋转的复合就是角度相加，得到的注意力分数只取决于两个位置之间的相对偏移，而不取决于其中任何一个绝对位置。
_避免使用_: 正弦编码（sinusoidal encoding，那是另一种加性机制，在投影之前施加于嵌入；RoPE 是乘性的，在投影之后作用于 Q 和 K，发生在注意力计算内部）

**缩放点积注意力（Scaled dot-product attention）**:
即运算 `softmax(QK^T / sqrt(d_k)) V`：用点积把一个查询与一组键做比较，通过缩放抵消方差随 `d_k` 增长的影响，用 softmax 把分数变成权重，再返回对应值的加权和。
_避免使用_: 注意力机制（attention mechanism，一旦指的是这种具体形式，这个说法就太含糊）

**自注意力（Self-attention）**:
查询、键和值都来自同一个输入序列的缩放点积注意力，所以每个位置都对同一序列中的每个位置（包括它自己）进行关注。
_避免使用_: 内注意力（intra-attention）

**SwiGLU**:
用 Swish（SiLU）激活做门控的 GLU 变体，用在大多数当前开源模型的前馈子层里，取代朴素的 ReLU 或 GELU 非线性。它用三个权重矩阵（两个上投影、一个下投影），而朴素的前馈块只用两个。
_避免使用_: GELU、ReLU（它们是固定的、单投影的非线性；当前的模型用 SwiGLU 带门控的两投影设计取代了它们）

**温度（Temperature）**:
生成期间，在产生下一个 token 分布的 softmax 之前，去除 logits 的一个值。小于 1 时，它让分布变得更尖锐，趋近贪心的行为；大于 1 时，它让分布变得更平坦。它重塑的是分布有多尖锐，并不决定哪些 token 有资格被采样。
_避免使用_: top-k、top-p（温度只重新缩放概率的尖锐程度；决定有资格的集合，是这些方法随后执行的另一个独立步骤）

**top-k 采样（Top-k sampling）**:
把下一个 token 的分布截断为概率最高的 `k` 个 token，丢弃其余的，再从这个大小固定、重新归一化的集合中采样。与核采样（top-p）不同，有资格的集合的大小永远不会随某一步的分布实际上是尖峰还是平坦而调整。
_避免使用_: 核采样（top-p）（nucleus sampling (top-p)，一种大小动态变化的替代方法；top-k 的截断个数是固定的，不管分布的实际形状如何）

**Xavier（Glorot）初始化（Xavier (Glorot) initialization）**:
按一层的扇入和扇出（它所连接的输入数和输出数）来缩放该层初始权重的方差，而不是对每一层都使用同一个固定方差，使激活值和梯度的方差在深层网络的各层之间大致保持一致，而不是每过一层就越积越小或越积越大。
_避免使用_: 不论层的大小，对每一层都使用单一固定的初始化方差（a single fixed initialization variance for every layer regardless of size，Xavier 初始化正是专门为了解决这个问题而设计的）
