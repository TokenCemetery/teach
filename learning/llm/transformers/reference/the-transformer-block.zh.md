## 位置编码

注意力本身没有顺序的概念；对调两个位置，只是把输出重新标注一下。位置必须在注意力运行之前，就写进嵌入本身。

```text
PE(pos, 2i)   = sin(pos / 10000^(2i / d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i / d_model))
```

| 方案 | 能否泛化到没见过的序列长度 | 实现 |
|---|---|---|
| 正弦式（固定公式） | 能，公式在任何位置都可以求值 | 没有需要学习的参数 |
| 学习得到的位置嵌入 | 不能，只有训练中见过的位置的行 | 一张查找表，像其他任何参数一样训练 |

## 残差连接与层归一化

```text
post-norm: LayerNorm(x + Sublayer(x))
pre-norm:  x + Sublayer(LayerNorm(x))
```

| 部件 | 解决什么 | 与什么无关 |
|---|---|---|
| 残差（`+ x`） | 梯度在深层堆叠中缩小或爆炸，办法是在每一层给它一条直接的恒等通路 | 子层自己的变换 |
| 层归一化 | 激活值的尺度逐层漂移，办法是对每个 token 自己的特征向量做归一化（在特征上求均值/方差，再施加学习得到的缩放和平移） | 批大小，这与批归一化不同，后者需要许多样本的统计量 |

**前归一化优于后归一化。** 前归一化让残差路径本身端到端完全不被归一化，是一条畅通无阻的恒等连接；后归一化则在每一层都对残差之和做归一化，破坏了那条路径。尽管原始论文选的是后归一化，当前大多数大模型用的是前归一化。

## 前馈块

```text
FFN(x) = max(0, x W1 + b1) W2 + b2
```

| 步骤 | 输入形状 | 输出形状 | 说明 |
|---|---|---|---|
| `x W1 + b1`，非线性 | `[n, d_model] × [d_model, d_ff]` | `[n, d_ff]` | `d_ff` 通常是 `d_model` 的 4 倍（原始论文中是 512 到 2048）；最初是 ReLU，后来的架构里是 GELU/SwiGLU |
| `... W2 + b2` | `[n, d_ff] × [d_ff, d_model]` | `[n, d_model]` | 投影回去，让结果加进残差流 |

相同地，用同样的权重，分别作用于每个位置，在这里没有任何位置会看到另一个位置的向量。这恰好与注意力互补：注意力在位置之间混合，但在权重算出之后，它对值是线性的；前馈块才是让单个位置自己的表示得到真正非线性重塑的地方。

## 堆叠块

| 性质 | 含义 | 为什么重要 |
|---|---|---|
| 保持形状 | 每个块输入 `d_model`，输出 `d_model` | 块 N 的输出成为块 N+1 的输入，无需适配器；同一种块的形状可以堆叠任意多次 |
| 不共享权重 | 每个块都有自己独立学习得到的参数 | 参数开销大致与深度成线性关系；换来的是不同的块在不同深度上分工 |
| 残差流 | 一个持续流动的向量穿过每个块，每个块各自加上自己的贡献 | 这正是第 5 课的残差/层归一化机制，在深度增加到几十个块时所要保护的东西 |

## 嵌入、输出与权重绑定

| 层 | 形状 | 作用 |
|---|---|---|
| 输入嵌入 | `vocab_size × d_model` | 第 `i` 行是 token `i` 学习得到的向量；查它是一次查找，而不是计算出来的变换 |
| 输出投影 | `d_model × vocab_size` | 在每个位置上，为每个词表 token 产生一个 logit |

这两个形状互为转置。**权重绑定**把嵌入矩阵转置之后，复用为输出投影（`logits = h @ W_embedding^T`），而不是学习第二个矩阵，理由是两个层联系的是同一个 token 的底层表示。

例题：词表 50,000，`d_model = 768`。嵌入表：`50,000 × 768 = 38,400,000` 个参数。不做绑定的输出层，需要一个同样大小的第二个矩阵；绑定去掉了它，在这里节省了大约 3840 万个参数，质量没有损失，往往还有可测量的提升。

## 信任一个完整模型的实现之前

- [ ] 位置编码是在第一个块之前，加到 token 嵌入上的，而不是以别的方式注入注意力。
- [ ] 每个子层都包在残差连接里，层归一化的放置（前归一化还是后归一化）是一个刻意的选择，而不是碰巧哪个教程用了哪个。
- [ ] 前馈块的两层先扩张再收缩（`d_model` 到 `d_ff` 再到 `d_model`），它的权重从不在位置之间共享。
- [ ] 堆叠中的每个块都接收并返回 `d_model`，并且各自拥有独立学习得到的权重。
- [ ] 如果使用了权重绑定，输出投影就是转置后的嵌入矩阵，而不是第二个学习得到的矩阵。
